# 新底板引脚分配方案（6 路 42 步进 + 2 路舵机）

> **状态：方案稿，未打样、未核对核心板排针、固件未改。** 2026-10-29 拟。
> 这份文档**不替代** `Docs/PINMAP.md`——`PINMAP.md` 记录的是**现在这块板**的实际接线，
> 本文是**下一块板**的分配建议。打样定稿后再另建 `PINMAP_v2.md` 或整体替换。

---

## 0. 前提（2026-10-29 与用户确认）

| 项目 | 结论 |
|---|---|
| 板子形态 | 继续用 **FK407M3-VET6 核心板**插在底板上（不动 MCU、不动 Keil 工程结构） |
| 底盘 | **4 × 42 步进**（麦轮），STEP/DIR 接口 |
| 机械臂 | **2 × 42 步进**（升降 + 旋转），STEP/DIR 接口 |
| 舵机 | **2 路** 50 Hz（机械臂 U5、载物台 U6） |
| 轮编码器 | **取消**（TIM2/TIM3/TIM4 释放出来） |
| 新增硬件 | 舵机独立稳压 + 信号串阻/TVS 保护 |
| 串口 | 调试、陀螺、树莓派、串口屏、蓝牙 五路都保留 |

电机驱动芯片按 **DRV8825 / TMC2209** 这一类"STEP + DIR + nEN + nFAULT"模块算。
MS1/MS2/MS3 细分选择**在 PCB 上用跳线/焊盘接死**（16 细分），不占 MCU 引脚。

---

## 1. 先看三条硬约束（决定了整张表）

### 1.1 一个定时器的多个通道共用 ARR —— 一个定时器只能出一种频率

这是整份分配的分水岭。老板上 4 路直流电机 PWM 放在 TIM1 的 CH1~CH4 是可以的（PWM 占空比
各通道独立，频率相同无所谓）。但**步进的 STEP 引脚要的是"每轴不同频率"的脉冲**：

- 前进：四轮同速 ✅
- 原地转：左前=左后=+v，右前=右后=−v（两侧反向）
- 横移：左前=−v，右前=+v，左后=+v，右后=−v（对角反向）

三种动作的"同速配对"完全不同，**没有任何固定分组能让两个轮子永远同速**。
所以：**四个轮子必须各占一个独立定时器**，机械臂两轴同理。

> 如果想省定时器，只能改走 TMC2209 的 UART 速度模式（模块内部产生脉冲）。
> 那属于换方案，不是换引脚。

### 1.2 引脚最终受"核心板排针"限制，不是受 F407 数据手册限制

FK407M3 只把部分 GPIO 引到 2.54 排针上（有些脚被板载 CH340、USB、晶振、按键占掉）。
下表是按 **F407VET6（LQFP100）的定时器资源** 推出来的，**打样前必须拿 FK407M3 的排针定义
逐条核对一遍**。表里打了 ★ 的是最容易出事的脚，见第 6 节。

### 1.3 PE5 已经烧了，新板要按"单点失效"来设计

2026-10-24 实测：PE5 的 GPIO 配置全对（MODER=2、AFR=3、TIM9 CCR1 会变），
但万用表量到的是浮空 1.68 V，**输出驱动/走线已损坏**。这是老板上唯一确认死掉的脚。

新板的设计原则：**任何一个引脚损坏，不能让整块板或整类功能停摆**。
舵机信号串 220 Ω + TVS 之后，这种损坏的概率会低很多，但分配上仍然不要"把两路舵机
背靠背挂在同一个 port 的相邻两个脚上就不留后路"。

## 2. 定时器分配总表

| 定时器 | 总线 | 用途 | 引脚 | 备注 |
|---|---|---|---|---|
| TIM1 | APB2 (168 MHz) | M1 左前轮 STEP | PE9 / CH1 | 高级定时器，可硬件计数脉冲（RCR） |
| TIM9 | APB2 (168 MHz) | M2 右前轮 STEP | **PE6** / CH2 | 老板上是 U6 舵机脚，新板改作步进 |
| TIM2 | APB1 (84 MHz) | M3 左后轮 STEP | PA0 / CH1 | **32 位**，底盘速度范围最大，给它 |
| TIM3 | APB1 (84 MHz) | M4 右后轮 STEP | PB4 / CH1 | PB4=NJTRST，只能用 SWD 调试 |
| TIM4 | APB1 (84 MHz) | M5 旋转台 STEP | PD12 / CH1 | |
| TIM13 | APB1 (84 MHz) | M6 升降台 STEP | PA6 / CH1 | 16 位，慢速时要改预分频（见 5.7） |
| TIM12 | APB1 (84 MHz) | 舵机 U5 + U6，50 Hz | PB14 / CH1、PB15 / CH2 | 同一个定时器两个通道，天然同频 |
| TIM7 | APB1 | 1 ms 节拍 / 100 Hz 控制环 | — | 无语义变化 |
| TIM6 | APB1 | 预留 | — | |
| TIM5 / TIM8 / TIM10 / TIM11 / TIM14 | — | **空闲** | — | 将来加 PWM/测频不用改板 |

一步到位的关键点：**六个轴 = 六个定时器，每轴只用 CH1（或 CH2）**，
这样以后想给某个轴加"第二路同步输出"或改用互补输出，都还有通道可用。

## 3. 引脚分配总表

### 3.1 步进（6 轴 × STEP/DIR，EN 与 FAULT 分组共用）

| 轴 | STEP | 定时器 | DIR | 说明 |
|---|---|---|---|---|
| M1 左前轮 | **PE9** | TIM1_CH1 | **PE7** | 老板上 PE9 是 A 电机 PWM，可直接沿用 |
| M2 右前轮 | **PE6** | TIM9_CH2 | **PE8** | |
| M3 左后轮 | **PA0** | TIM2_CH1 | **PE10** | 32 位定时器，底盘速度范围最大 |
| M4 右后轮 | **PB4** | TIM3_CH1 | **PE12** | 老板上 PB4 是编码器 B |
| M5 旋转台 | **PD12** | TIM4_CH1 | **PE13** | 老板上 PD12 是编码器 C |
| M6 升降台 | **PA6** | TIM13_CH1 | **PE14** | |

| 共用信号 | 引脚 | 极性/接法 |
|---|---|---|
| 底盘 nEN（M1~M4） | **PD3** | 低有效；**板上 10 k 上拉**，上电默认禁用 |
| 机械臂 nEN（M5~M6） | **PE15** | 低有效；10 k 上拉，可单独断电 |
| 步进总故障 nFAULT | **PD4** | 6 路 nFAULT 开漏线或，10 k 上拉，低有效 |

**为什么 DIR 全放 GPIOE（PE7/8/10/12/13/14）**：六个方向位都在同一个 `GPIOE->ODR` 里，
一次写入改完所有方向，不会出现"改了三个、第四个还没改"这种半个拍子。
这是老板上做不到的（当时 DIR 分散在 PE 和 PB 两个 port）。

### 3.2 舵机（2 路，同一个定时器）

> **as-built 差异（2026-11-03 网表核对）**：本节有两处没按这张表做——M4 的 STEP 用
> **PB0 / TIM3_CH3**（不是 PB4 / CH1），机械臂独立使能没有用 PE15，改成 **PC8=旋转、PC9=升降**。
> 舵机两路与本表一致（PB14/PB15 + TIM12，2026-11-09 已进固件）。
> 以 `Docs/交接文档_新底板V2.md` §2 与 `BSP/Inc/pins/stepper6.h` 为准，本表是打样前的方案。

| 功能 | 引脚 | 定时器 | 保护 |
|---|---|---|---|
| U5 机械臂舵机 | **PB14** | TIM12_CH1 | 串 220 Ω + 5.1 V TVS 到地 |
| U6 载物台舵机 | **PB15** | TIM12_CH2 | 串 220 Ω + 5.1 V TVS 到地 |

- 3.3 V 逻辑直接驱动（绝大多数舵机 VIH < 2.5 V，够）。
- **舵机电源单独 5~6 V BEC**，不跟 MCU 5 V 共用；每条电源线就近 470 µF + 100 nF。
- 信号地单点回到 MCU 地，**不要**和电机功率地一起走。

### 3.3 串口（五路全留）

| 用途 | 引脚 | 外设 | 波特率 | 备注 |
|---|---|---|---|---|
| 调试 | PA9 / PA10 | USART1 | 115200 | 核心板自带 |
| 陀螺 HWT101 | **PA2 / PA3** | USART2 | 115200 | ⚠ **不 5V 容忍**，只能 3.3 V 逻辑 |
| 树莓派 | PC10 / PC11 | USART3 | 115200 | PC10→Pi 脚 10(RXD)，PC11←Pi 脚 8(TXD) |
| 串口屏 TJC | PC6 / PC7 | USART6 | 115200 | |
| 蓝牙 HC-05 | **PC12 / PD2** | UART5 | 9600 或 115200 | 老板上 USART2 被陀螺占，这里单独给一路 |

雷达 RPLIDAR C1 不接 STM32，走树莓派 USB；板上只留一组 **5 V / GND 排针**给它供电。

### 3.4 I2C

| 用途 | 引脚 | 外设 | 备注 |
|---|---|---|---|
| SCL / SDA | PB6 / PB7 | I2C1 | 板上 **4.7 k 上拉到 3.3 V**（老板缺，是隐患） |
| MPU6050 INT | PC3 | EXTI | |
| TOF400C INT | PC2 | EXTI | |
| TOF400C SHUT | **PD5** | GPIO 开漏 | 老板上 PC1 悬空没接；**PC1 是核心板按键，别用** |
| 预留 | PB10 / PB11 | I2C2 | 二路 TOF / OLED |

### 3.5 开关、按键、指示灯、ADC

| 功能 | 引脚 | 备注 |
|---|---|---|
| 上限位 | PD6 | 上拉输入，RC 滤波（10 k + 100 nF） |
| 下限位 | PD7 | 同上 |
| 原点 | PD8 | 同上 |
| 用户按键 | PD9 | 老板上在 PB3(JTDO)，新板换普通脚 |
| 状态 LED | PC0 | 低电平点亮，沿用 |
| 电池电压采样 | PA4 | ADC1_IN4，分压 1/11 |
| 总电流采样 | PA5 | ADC1_IN5（可选） |

> PA4/PA5 同时是 SPI1 的 NSS/SCK。**做 ADC 就用不了 SPI1**——要上 ICM-42688 这类 SPI IMU
> 的话，这里二选一，IMU 改走 I2C2。

## 4. 与老板的差异（改动清单）

| 功能 | 老板 | 新板 | 为什么要改 |
|---|---|---|---|
| 4 路直流电机 PWM | TIM1 CH1~4（PE9/11/13/14） | TIM1/9/4/3 各一轴 | 步进需要每轴独立频率 |
| 4 路轮编码器 | TIM2/TIM3/TIM4 + PD8/PD9 EXTI | **取消** | 用户决定不用编码器 |
| 舵机 U5 | PA7（TIM14_CH1，跳线） | PB14（TIM12_CH1） | 把 PA7/SPI1 还回来 |
| 舵机 U6 | PE6（TIM9_CH2） | PB15（TIM12_CH2） | 两路舵机同一个定时器，天然同频 |
| 步进 U1/U4 | DRV8825 PD0/PD1、PD4/PD5 | PD12/PB4 等 6 轴 | 轴数从 2 变 6 |
| 蓝牙 | PA2/PA3（被陀螺抢走） | UART5 PC12/PD2 | 陀螺和蓝牙各占一路，不用二选一 |
| TOF SHUT | 悬空 | PD5 | 两个 TOF 共存必须能单独复位 |
| I2C 上拉 | 无 | PB6/PB7 上 4.7 k | 老板靠模块自带，总线长了会挂 |
| 板载按键 | PB3(JTDO) | PD9 | PB3 是新板 M4 的邻居，别抢 |
| 预留 SPI | PA4~PA7 | 无（PA4/PA5 给 ADC） | 需要 SPI IMU 就改走 I2C2 |

## 5. 为什么这么分（决策理由，便于以后改）

1. **STEP 一定放定时器脚，DIR 一定放普通 GPIO**。DIR 变化频率是"每次换向一次"，
   不需要硬件；STEP 需要精确频率和占空比，必须硬件产生。
2. **每个轴独占一个定时器**（见 1.1）。代价是引脚分散在 A/B/D/E 四个 port，
   底板布线时把 STEP 当成"6 根等长无关的信号"走，不用强求成组。
3. **两路舵机放 TIM12**，因为它是唯一一个"两个通道都在 PB14/PB15、且这两个脚在老板上没被
   关键功能占用"的定时器。TIM1 的 CH3/CH4 虽然也在 PE13/PE14，但那两个脚更适合当 DIR。
4. **PA7 还给 SPI1**。老板上因为 PE5 烧了临时把机械臂舵机挪到 PA7(TIM14_CH1)，
   代价是 SPI1 的 MOSI 被吃掉。新板不需要这个临时措施。
5. **USART2 留给陀螺，蓝牙挪到 UART5**。老板上这两者抢同一个串口，导致
   `WHEEL` Target 的调参口和陀螺口必须同时接，且一换就忘（踩过坑）。
6. **ADC 放 PA4/PA5**。老板上 PA2/PA3 原本是模拟预留，被改成 USART2 之后
   全板再没有 ADC 可用，这是"想做堵转检测却做不了"的根因。
7. **只有 TIM2 是 32 位**，其余 STEP 定时器都是 16 位。16 位定时器在**很低**的步进频率下
   （比如 500 Hz，ARR 要 336000）会溢出，必须在运行时改预分频——**预分频只能在更新事件时生效，
   改的那一拍会丢一个脉冲**。所以把 32 位的 TIM2 给了底盘（底盘速度跨度最大），
   机械臂两轴速度低、行程短，丢一拍可以接受。固件里要给每轴做"预分频 + ARR"两段式计算。
8. **PB14/PB15 同时是 SPI2 的 MISO/MOSI**。本方案把舵机放在这里，就意味着**放弃 SPI2**。
   将来要上 SPI 陀螺只能走 I2C2（或重新分配舵机脚）。

## 6. 打样前必须核对的 5 件事

1. **核心板排针定义**（★ 最高优先级）：逐条确认下表 30 个脚都真的引到排针上了，
   且没有被板载外设（CH340、USB、SD、按键、LED、晶振）吃掉。
2. **PD0 / PD1 ★**：在部分 F407VET6 板子上这两个脚是 HSE 晶振脚。
   老板上它们接 DRV8825 的 STEP/DIR 且系统能跑，说明 FK407M3 的晶振不是这两个脚——
   但新板**不要碰 PD0/PD1**，本方案已经避开。
3. **PB2 / BOOT1 ★**：不要用。本方案已避开。
4. **PB3 / PB4 / PA15 ★**（JTAG 脚）：只能用 SWD 调试。老板上 PB3(按键)、PB4(编码器 B)
   已经在用且能跑，说明可行，但下载器必须设成 **SWD 模式**。
5. **PE5**：确认新板这份网表里没有任何网络连到 PE5。

## 7. 电源与保护（顺带的，但比引脚更容易翻车）

- **24 V 主电源**：42 步进通常 24 V 才有力气。6 轴 × 1.5 A ≈ 9 A 峰值，
  选 **24 V / 15 A** 电源，入口加自恢复保险丝 + 反接保护 MOS + TVS。
- **待测**：DRV8825 是 8~45 V / 1.5 A（散热后 2.2 A 峰值），24 V 下长期 1.5 A 会烫；
  TMC2209 是 4.75~29 V / 2 A RMS，24 V 更合适且带 DIAG 输出。**选型前先量实际相电流**。
- **每个驱动器就近**：100 µF 电解 + 100 nF 瓷片，电机线双绞。
- **地**：功率地（电机/驱动器）与信号地（MCU/传感器）**单点汇合**在电源入口，
  不要把电机回流电流放到 MCU 地平面下面。
- **舵机**：独立 5~6 V BEC ≥ 3 A，信号串 220 Ω + TVS。PE5 那次损坏最可能就是这条路。
- **层数**：至少 4 层（信号 / GND / 电源 / 信号），24 V 和电机走线 ≥ 2 mm。

## 8. 对固件的连带影响（做板的同时要提前知道）

这一步改下来，`BSP` 层几乎是重写：

- `board_motion.c`：4 路直流 PWM + 2 路 DRV8825 → **6 路步进脉冲发生器**
  （每轴一个定时器、速度斜坡、位置积分），`Motor_Set/Motor_Brake` 语义消失。
- `board_encoder.c`：4 路编码器全部删除；里程计改由**步进计数**推算。
- `board_wheel.c`：速度闭环没有编码器就无法闭环——要么保留开环逆解 + 步数积分，
  要么后面换成 ZDT 闭环模块。
- `pins/` 下 `tb6612_u2.h`、`tb6612_u3.h`、`encoder_*.h`、`servo_u5.h` 全部重写；
  新增 `stepper_m1.h` ~ `stepper_m6.h`（或一个 `steppers.h` 统一放 6 轴）。
- `Tests/` 里 `RIG`、`WHEEL`、`Motors_*`、`ENCODER` 这些 Target 的判据全部作废，要重写。

**建议顺序**：先把新板的 6 轴点亮（只发固定频率脉冲，听声音/看轴转），
再接树莓派/屏/陀螺，最后再谈里程计和导航。
