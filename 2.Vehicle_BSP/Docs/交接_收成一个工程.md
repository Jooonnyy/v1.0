## 3. 必须守住的行为

新底板和旧编码器底盘抢 TIM2/TIM3/TIM4。生产入口只能 `Board_InitStep6()`。谁把 `Board_Init()`、`ChassisOdom_Update()`、`Vision_Poll()` 加回 `VehicleApp_Begin/Poll`，谁就把 STEP 引脚抢走。

不要把 `HMI` / `RIG` / `WHEEL` 的命令并进 `vehicle_app.c`。`M`、`L`、`TASK`、`STOP` 和底盘命令重名，并进去就会改掉现在的效果。升降、旋转、舵机、串口屏留在 BSP，这次不挂入口。

下面这些看起来像瑕疵，是原台架的行为，不要「顺手修」：

- 上电横幅仍是 `CHASSIS_STEP ready. 4 steppers, open loop, no encoder.`
- `J` 即使 `JogStart` 已经回了 `ERR`，后面仍会再打一行 `J <axis> <steps> steps @ <hz> Hz`
- 有线口只认 CR/LF；蓝牙口静默 50 ms 也断帧（`CS_LINE_IDLE_MS`）
- 超长命令当场回 `ERR command too long`，不更新回复口
- `STOP` / `E 0` 取消任务时回的是 `TASK aborted`，没有冒号；运动超时回的是 `TASK aborted: move timeout`
- 手动 `A <deg>` 走完后会把指令航向写回去。这是原 `cs_move_spin` 的 `set_heading=1`，不是新功能
- 步数仍是 `频率 × 时间` 的开环估算，不要加编码器

参数只许改 `App/Inc/chassis_config.h`，并保持已有的 `#error`。不要在函数体里写新的魔法数。
