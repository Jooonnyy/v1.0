## 接线与设置

| 接口 | 现有工程引脚 |
|---|---|
| 蓝牙 TXD → STM32 RX | PA3 / USART2 |
| 蓝牙 RXD ← STM32 TX | PA2 / USART2 |
| 蓝牙串口参数 | 115200、8 数据位、无校验、1 停止位 |
| U1 STEP | PD0 |
| U1 DIR | PD1 |
| U1 EN | PC8，程序输出低电平使能 |
| U1 ALM | PD14，程序将低电平解释为报警 |

逻辑信号须共地；PA2/PA3 按 3.3V 逻辑连接。X42S 的 PLC 输入接法、输入电压、EN/ALM 极性需要按实物手册核对，表格只说明 MCU 侧代码，不能直接代表 PLC 端子的接法。驱动器应设为 STEP/DIR（脉冲+方向）控制模式。

蓝牙模块的数据波特率须匹配 MCU。若使用现有双 HC-05 透传链路，电脑侧 USB-TTL 串口同样设为 115200 8N1。若由手机直接连接，车上模块须可被手机连接（例如 HC-05 从机）；主机绑定另一模块的配置不能直接用于手机连接。模块具体配置见工程 `Docs/HC05无线串口.md`，按实际型号和固件确认。

## 首次操作

1. 支撑好平台，确保两个方向都有余量，下载 `Stepper_ZDT` 固件。上电不发脉冲，U1/U4 初始均失能。
2. 调试助手使用 ASCII/文本发送，关闭 HEX 和循环发送；每条命令末尾追加 CR、LF 或 CRLF。蓝牙连上后发送 `?`，应返回命令表；启动信息可能在连接前已经发完。
3. 按下列顺序逐条发送，收到回复再发送下一条：

```text
STATUS
E 1
V 2000
D 1
J 20
```

`V 2000` 是 2000 微秒脉冲周期（名义 500 脉冲/秒）。`J 20` 只发送 20 个脉冲。观察实际升降方向，完成后返回 `steps done` 和 `status: idle`。

4. 首次动作结束后再发送 `D 0`、`J 20`，观察反向运动。D 1/D 0 只表示 DIR 的两种逻辑，尚不能标为上升/下降。
5. 随时发送 `STOP` 加换行停止发脉冲。STOP 和点动结束都保留当前使能状态；只有 `E 0` 主动释放电机，带载时先支撑平台。

细分和丝杆导程尚未确认，因此步数不换算成毫米。按控制脉冲估算位移：`位移mm = 脉冲数 × 导程mm / 每转脉冲数`；40mm 电机机身长度不等于导程。

## 命令

| 文本命令 | 含义 |
|---|---|
| `?` / `HELP` | 帮助 |
| `STATUS` | 当前模式、使能、方向、周期、报警输入 |
| `STOP` | 停止脉冲、取消自动流程、保留使能 |
| `E 1` / `E 0` | 使能 / 释放 |
| `V 2000` | 设置脉冲周期，允许 20..20000 微秒 |
| `D 1` / `D 0` | 设置方向 |
| `J 20` | 点动指定脉冲数；单独 `J` 默认 20 |
| `F` | 查询报警输入（1 表示输入低） |
| `A 1` / `A 0` | 报警输入触发时停止 / 仅观察，默认 0 |
| `R` | 显式运行一轮原速度档往返，每方向 400 脉冲；首次不使用 |
| `G` | 连续运动，首次不使用 |
| `S` | 连续加速扫描，首次不使用 |

运动期间的回显暂存，等停止或自动暂停阶段发送，避免阻塞串口打断脉冲；暂存满时停止后提示 `WARN deferred replies dropped`。运行中没有周期性串口打印。发 `STOP` 后应看到 `stopped` 和 idle 状态。

目前不是带回零和毫米软行程的升降控制：没有启用硬限位，没有蓝牙连接状态检测，断线不会立即停车；保留原单阶段 60 秒超时。首次只使用有限步数点动，不能用蓝牙代替硬件急停。往返脉冲数相等不能保证实际位置无漂移。

## 排查

- 能连接但 `?` 没回复：确认烧的是 Stepper_ZDT、蓝牙接 PA2/PA3、模块数据波特率为 115200、文本命令带换行。
- 有回复但不动：先核对驱动电源、STEP/DIR 模式、EN 电平和 PLC/TTL 输入接线。
- 方向相反：点动停止后切换 D 0/D 1。
- ALM 接线与极性未核实前，不把 A 1 当作已验证保护。
