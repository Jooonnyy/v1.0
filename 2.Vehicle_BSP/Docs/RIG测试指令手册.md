## 1. 怎么连、怎么发

- 串口：**USART2 / PA3(TXD) PA2(RXD) / 115200 8N1**，接 HC-05 蓝牙（或改 `RIG_PORT` 走有线口重编）。
- 指令一律 **ASCII**，**大小写不敏感**（固件统一转成大写），末尾需要 **CR / LF / CRLF** 之一。
- **单条指令最长 39 个字符**（`RIG_CMD_LEN = 40`，含结尾 `\0`）；超长回 `ERR command too long`。
- 空行忽略。
- 没有参数分隔符限制：`M a 250`、`M a250`、`A90` 都行（`parse_arg` 跳过前导空格）。
- **遥测与回显共用同一个口**：打开 `T 1` 后，数字流会和文本回显交错，看波形时别同时敲指令。

## 2. 上电初态（先读这一节）

固件上电**不会自己动**：

| 对象 | 上电状态 |
|---|---|
| 升降台/旋转台（ZDT） | **不发脉冲**、`en=0`（失能，没有保持力矩） |
| 机械臂 / 载物台舵机 | **不出 PWM**（定时器配好但通道不输出） |
| 四路底盘电机 | 输出 0，两片 TB6612 处于**待机**（STBY=0） |
| 心跳灯 PC0 | **500 ms 翻转一次（1 Hz）** = 固件在主循环里跑 |

心跳灯的两个用途：**停住不闪 = 主循环卡死**（串口阻塞、脉冲预算吃满），比串口回显更早暴露问题；
**完全不亮 ≠ 故障**，因为 Vehicle_BSP 不驱动 PC0，只有 RIG 这类显式调 `Led_StatusInit()` 的入口才亮。
⚠ 心跳灯（PC0，低电平点亮）和核心板上**硬连 USB 5V 的电源指示灯**不是一回事，别混。

## 3. 指令总览

### 3.1 全局

| 指令 | 参数 | 作用 |
|---|---|---|
| `?` 或 `HELP` | — | 打印帮助（分多行） |
| `S` 或 `STATUS` | — | 两轴 + 两舵机 + 四路电机状态，共 4 行 |
| `H` | — | 直接打印 TIM9 / TIM1 关键寄存器 + STBY 电平 |
| `STOP` | — | 两轴停脉冲（**保留使能**）+ 四路电机全停回待机；**若正在做角度运动**（`PT`/`PA`）则载物台顺手回中位。⚠ **不停 `P <permille>` 的连续转**，那种情况要 `P 0` 或 `PO` |
| `Z` | — | 两轴累计步数清零 + 载物台角度清零 |
| `T 0` / `T 1` | 0 或 1 | 遥测流 关 / 开（默认关，5 Hz） |
| `ALM 0` / `ALM 1` | 0 或 1 | 是否采信驱动器 ALM 输入（默认 0 = 忽略） |
| `PICK` | — | 跑一轮完整"抓取 → 回位"序列（单次；`STOP` 或任意手动运动命令中止） |

### 3.2 升降台 LIFT（U1）与旋转台 ROT（U4）

两轴指令**前缀不同、后缀相同**：`L` = 升降台（U1），`R` = 旋转台（U4）。

| 指令 | 参数 | 作用 |
|---|---|---|
| `LE 0/1`、`RE 0/1` | 0 或 1 | 轴使能 / 释放（**EN 低有效**，`1` = 拉低使能） |
| `LV <us>`、`RV <us>` | 20..20000 µs，默认 2000 | 脉冲周期（周期越小转得越快） |
| `LD 0/1`、`RD 0/1` | 0 或 1 | 方向 |
| `LJ [n]`、`RJ [n]` | 1..200000，默认 20 | 点动 n 步 |
| `LC 0/1`、`RC 0/1` | 0 或 1 | 连续转 开 / 停 |

### 3.3 机械臂舵机 ARM（U5：PA7 默认 / PE5 可选）

> 接法由 `BSP/Inc/pins/servo_u5.h` 的 **`U5_SERVO_USE_PA7`** 决定：
> **`1`（默认）= PA7 / TIM14_CH1**（需把舵机信号线接到 PA7）；**`0` = PE5 / TIM9_CH1**（老板原设计）。
> 2026-10-24 现场判据：老板上 PE5 的寄存器全对（`CEN=1`、`CC1E=1`、`CCR1` 正确、`MODER=2/AFR=3`），
> 但引脚恒浮空 1.68 V、不随 `AU` 变化；同颗舵机插 U6 能转 ⇒ 当时判定 PE5 输出损坏，故默认走 PA7。
> ⚠ 改宏必须重编，**并且硬件接线要跟着换**，只改代码不动线不会工作。
> （新板按 `Docs/新板引脚分配_6路步进.md` 规划是 PB14/TIM12_CH1，与这里都不同，以实际板为准。）

| 指令 | 参数 | 作用 |
|---|---|---|
| `A <deg>` | 0..180° → 1000..2000 µs | 位置型舵机，转到该角度刻度（1° ≈ 5.56 µs） |
| `AU <us>` | 500..2500 µs | 直接给脉宽（绕过角度换算，标定用） |
| `AO` | — | 关 PWM（掉力矩） |

### 3.4 载物台舵机 PLT（U6 / PE6 / TIM9_CH2）

> ⚠ 2026-10-13 现场：**这台舵机已烧坏**，机械臂那路正常。换件之前本节指令不会有可观察动作。

| 指令 | 参数 | 作用 |
|---|---|---|
| `P <permille>` | −1000..1000，**0 = 停** | 连续旋转型：千分比 = 速度（±1000 → 2000/1000 µs） |
| `PU <us>` | 500..2500 µs | 直接给脉宽（标定 / 排查用） |
| `PO` | — | 关 PWM（掉力矩） |
| `PT <deg>` | −3600..3600 | **相对**当前角度转 |
| `PA <deg>` | −3600..3600 | 转到**绝对**角度 |
| `PS <deg>` | −3600..3600 | 把"当前角度"设成该值（对零 / 标定） |
| `PM <ms>` | 80..20000，正负 = 方向 | **固定速度只给时间**：用 `RIG_PLT_SPEED_PERMILLE`（当前 400‰）转这么久，到点自动停 |

### 3.5 夹爪 GRIP（与机械臂共用同一路 U5 舵机）

| 指令 | 作用 |
|---|---|
| `GRIP` | 完整流程：夹紧 1724 µs → 保持 5000 ms → 每 400 ms 退 12 µs → 到 1389 µs 结束 |
| `GRIP H` | 只夹紧并保持（等 `GRIP O` 或 `STOP`） |
| `GRIP O` | 直接松开到 1389 µs |

### 3.6 四路底盘电机 MOTOR（TB6612 U2/U3，TIM1 四路 20 kHz）

| 指令 | 参数 | 作用 |
|---|---|---|
| `M` | — | 四路当前占空比 + 序列进度 |
| `MM` 或 `M ?` | — | 通道映射表（`M ?` 额外打印电机帮助） |
| `M <a-d> <permille>` | a/b/c/d，±250 | 单独驱动一路（0 = 停这一路；会自动中止 `MR`） |
| `MALL <permille>` | ±250 | 四路同时给同一占空比（**0 = 全停回待机**） |
| `MR` | — | 跑 12 段开环序列（≈14 s） |
| `MS` | — | 中止序列，四路全停回待机 |

> ⚠ **转电机前把四个轮子架空**；12 V 电机在 15%（150‰）以下可能低于启动死区而不转。

## 4. 每条指令的回显与判据

回显均为 ASCII，行尾 `\r\n`（遥测流例外，见 4.8）。

### 4.1 全局

| 指令 | 回显样例 | 判据 / 备注 |
|---|---|---|
| `?` | 多行帮助，含 `PC0 LED blinks = firmware alive...` | 能回 = 串口通 |
| `S` | `LIFT(U1) en=0 dir=1 period=2000us moving=0 rem=0 pos=0 alm=0 almen=0`<br>`ROT(U4) ...`<br>`ARM(U5/PA7) pos on=0 pulse=1500us grip=0 \| PLT(U6/PE6) cont on=0 pulse=1500us speed=0/1000 ang=0 turn=0 \| stream=0`<br>`MOTOR A=0 B=0 C=0 D=0 /1000 limit=250 seq=0 step=0/12` | `en` 使能、`rem` 点动剩余步数、`pos` 累计步数、`alm` 原始电平、`almen` 是否采信；`on` = 舵机是否出 PWM；`turn` = 载物台角度运动是否在跑 |
| `H` | **PA7 方案（默认）**：`H SERVO ARM TIM14 CEN=1 CCER=0x1 CCR1=1500`<br>`H SERVO PLT TIM9  CEN=1 CCER=0x10 CCR2=1500`<br>`H SERVO PINS PA7 MODER=2 AFR=0x9 \| PE6 MODER=2 AFR=0x3`<br>**PE5 方案**：`H SERVO TIM9 CEN=1 CCER=0x11 CCR1=1500 CCR2=1500`<br>`H SERVO PINS PE5 MODER=2 AFR=0x3 \| PE6 MODER=2 AFR=0x3`<br>其余：`H MOTOR TIM1 ...` / `H MOTOR STBY ...` | **判断"PWM 有没有真发出去"的唯一硬证据**。舵机定时器周期 20000（20 ms / 50 Hz），CCR 单位 1 µs；TIM1 周期 8400（20 kHz），250‰ 时对应 CCR **2100**。`MODER=2` 才是复用功能；`AFR=0x9` 是 AF9(TIM14)、`0x3` 是 AF3(TIM9) |
| `STOP` | `stopped: axes halted (still enabled), motors off` | 轴**仍使能**（有保持力矩），`LE 0` / `RE 0` 才释放。只在 `plt_move_active` 时载物台回中位（即 `PT`/`PA` 进行中）；**`P <permille>` 的连续转不会被它停掉** |
| `Z` | `pos and platform angle zeroed` | 清零是"参考点"，不是回零动作 |
| `T 1` / `T 0` | `stream on` / `stream off` | 见 4.8 |
| `ALM 1` | `ALM honored: stops on low ALM input` | PD14/PD15 悬空读高 = 无报警；没接线时保持 `ALM 0` |

### 4.2 升降台 / 旋转台

| 指令 | 回显样例 | 判据 / 备注 |
|---|---|---|
| `LE 1` | `LIFT(U1) enabled` | 运动中会被拒绝：`ERR axis is moving; send STOP first` |
| `LE 0` | `LIFT(U1) released (hold the load first)` | 带载释放会直接掉平台 |
| `LV 2000` | `LIFT(U1) period=2000 us` | 20..20000；越小越快，越容易丢步 |
| `LD 0` | `LIFT(U1) dir=0` | 运动中拒绝，先 `STOP` |
| `LJ 20` | `LIFT(U1) jog 20 steps` | 未使能回 `ERR axis disabled; send LE 1 / RE 1 first` |
| `LC 1` | `LIFT(U1) continuous=1` | 停用 `LC 0` 或 `STOP` |
| 点动完成 | `LIFT(U1) stopped, pos=20 steps` | 只在"动 → 停"的边沿报一次 |
| 驱动器报警 | `ALM LIFT(U1): pulses stopped (check driver alarm)` | 仅在 `ALM 1` 时出现 |

- 两个轴**没有软限位、没有回零**：第一次只发小步数，先确认方向与行程。
- 脉冲是阻塞发的，主循环按时间预算分批发，所以 `STOP` 和指令随时有响应。

### 4.3 机械臂舵机

| 指令 | 回显样例 | 判据 / 备注 |
|---|---|---|
| `A 90` | `ARM(U5/PA7) pulse=1500 us` | 90° → 中心 1500 µs；判据：动作平滑、无堵转嗡鸣 |
| `A 0` / `A 180` | `pulse=1000 us` / `pulse=2000 us` | 映射到**机械可用范围** 1000..2000（500/2500 是电气极限，会顶死） |
| `AU 1450` | `ARM(U5/PA7) pulse=1450 us` | 直接用这个循环微调，直到机构到位 |
| `AO` | `ARM(U5/PA7) off` | 掉力矩，机构可能自重下落 |
| 越界 | `ERR angle 0..180 deg` / `ERR pulse 500..2500 us` | — |
| 手动给 `A` / `AU` / `AO` | — | **会中止正在跑的 GRIP 流程**（手动优先） |

### 4.4 载物台舵机（连续旋转型）

| 指令 | 回显样例 | 判据 / 备注 |
|---|---|---|
| `P 1000` | `PLT(U6/PE6) pulse=2000 us` | **会一直转**，直到 `P 0` 或 `PO`（**`STOP` 不会停它**）。速度 = 千分比 |
| `P 0` | `PLT(U6/PE6) pulse=1500 us` | 1500 µs = 停；中位 ±25 µs 是死区，避免"给 0 还在爬" |
| `P -1000` | `pulse=1000 us` | 反向满速（方向反了改 `RIG_PLT_DIR_SIGN`，不用动接线） |
| `PU 1500` | `PLT(U6/PE6) pulse=1500 us` | 绕过千分比映射，直接给脉宽 |
| `PO` | `PLT(U6/PE6) off` | 关 PWM |
| `PT 90` | `PLT turning 90 deg in 1000 ms (open loop, 1000 permille)`<br>停稳后 `PLT done, angle=90 deg` | 相对转；相对对象的"当前角度"是**开环累计值**，不是真实反馈 |
| `PA 180` | `PLT turning 180 deg in 2000 ms (open loop, 1000 permille)` | 转到绝对角 |
| `PS 0` | `PLT angle set to 0 deg` | 对零（比如先手动摆正，再 `PS 0`） |
| `PM 1000` | `PLT timed 400 permille for 1000 ms`<br>到点 `PLT timed done; angle ref lost, PS or Z to re-zero` | 只给时间、速度由固件定（`RIG_PLT_SPEED_PERMILLE`）；**跑完角度基准失效**。`PM -1000` 反向 |
| 已在目标 | `PLT already at target` | 差值归一化后为 0；**不是故障** |
| 越界 | `ERR angle -3600..3600 deg` / `ERR speed -1000..1000 permille (0 = stop)` | — |

**角度是怎么算的**（开环时间法）：

```text
运行时间 ms = 角度差 ÷ RIG_PLT_DEG_PER_S × 1000      // 当前 90 °/s，⚠ 未标定
再夹到 [RIG_PLT_MIN_RUN_MS, RIG_PLT_MAX_RUN_MS]      // 当前 80 ms .. 20000 ms
```

- `RIG_PLT_ONEWAY = 1`：**总是单向转到位**（消回差，但路径可能更长）。从 90° 去 10° 会走 +280°，不是 −80°。
  想要最短路径改成 `0`。
- 角度会**累计越过 360°**（370 → 380 → …），`P`/`PA`/`PS` 里写 10 和 370 是同一个角。
- 到点后自动回 1500 µs 停（**不是保持位置**，连续旋转舵机没有位置保持）。
- ⚠ **没有堵转保护**：如果机构有机械限位，`PT`/`PA` 累计角度或 `P <permille>` 会让它顶死在限位上持续
  堵转发热。调试阶段建议 `RIG_PLT_ONEWAY` 改 `0`、把 `RIG_PLT_MAX_RUN_MS` 收小、`P` 之后随手 `P 0`。

### 4.5 夹爪

| 指令 | 回显样例 | 判据 / 备注 |
|---|---|---|
| `GRIP` | `GRIP close 1724 us (=1694+30), hold 5000 ms then open` | 夹紧带 30 µs 超压；随后每 400 ms 一行 `pulse=... us`，结尾 `GRIP open; done` |
| `GRIP H` | `GRIP hold closed at 1724 us (=1694+30). GRIP O to open.` | 保持夹紧，最长堵转 = 保持时间 |
| `GRIP O` | `GRIP open at 1389 us` | 直接松开 |
| `STOP` | — | **中止流程但保持当前脉宽**（不会掉料） |

对照实验：把 `RIG_GRIP_OVERSHOOT_US` 改 `0` 重编，比较"手能不能掰开夹爪"，判断超压有没有用。

### 4.6 四路底盘电机

| 指令 | 回显样例 | 判据 / 备注 |
|---|---|---|
| `M` | `MOTOR A=250 B=0 C=0 D=0 /1000 limit=250 seq=0 step=0/12` | `limit` 是硬限幅；`seq`/`step` 是 `MR` 进度 |
| `MM` | 4 行通道映射 + `M ?` 额外 4 行帮助 | 先把映射对着实物核一遍 |
| `M a 250` | `MOTOR A = 250/1000` | 只有 A 转；`H` 里 `CCR1` 应 = **2100**、`STBY PD2=1` |
| `M c 250` | `MOTOR C = 250/1000` | `H` 里 `CCR3` 应 = 2100、`STBY PD3=1` |
| `M a 0` | `MOTOR A = 0/1000` | 只把这一路写 0，**不会**把驱动器压回待机 |
| `MALL 250` | `MOTOR all four = 250/1000` | 先 `Motor_Standby(0/1,1)` 唤醒两片 TB6612 |
| `MALL 0` | `MOTOR all stopped (drivers standby)` | 四路 0 + 待机 |
| `MR` | `MOTOR sequence start; LIFT THE WHEELS OFF THE GROUND; MS/STOP to abort`<br>每段一行 `MOTOR [n/12] ...` | 见下方 12 段表 |
| `MS` | `MOTOR stopped, drivers standby (sequence aborted)` | 立即全停回待机 |
| 序列跑完 | `MOTOR sequence done, all stopped. MR to rerun` | 自动全停 |
| 硬超时 | `MOTOR hard timeout, all stopped` | 40 s 到时无条件全停 |
| 越限 | `ERR motor limit +/-250/1000` | — |

`MR` 的 12 段（跑段 1500 ms，间隔 800 ms，合计 ≈ 14 s）：

| 段 | 动作 | 段 | 动作 |
|---:|---|---:|---|
| 1 | A 正转 | 7 | D 正转 |
| 2 | all stop | 8 | all stop |
| 3 | B 正转 | 9 | 四路同时正转 |
| 4 | all stop | 10 | all stop |
| 5 | C 正转 | 11 | 四路同时反转 |
| 6 | all stop | 12 | all stop |

**通道映射**（对着实物核）：

| 通道 | TB6612 | PWM | IN1 | IN2 | STBY |
|---|---|---|---|---|---|
| A | U2 通道 A | PE9 | PE7 | PE8 | PD2 |
| B | U2 通道 B | PE11 | PE10 | PE12 | PD2 |
| C | U3 通道 A | PE13 | PB11 | PB12 | PD3 |
| D | U3 通道 B | PE14 | PB13 | PB14 | PD3 |

⚠ 已知的坑：`Motor_Set()` **不碰 STBY**，而 `Motor_StopAll()` / `MS` / `STOP` 会把两片压回待机。
所以 `MS` 之后单独发 `M a 250` 是会自动唤醒的（`motor_manual_channel` 里有 `Motor_Standby`），
但**任何直接写 CCR 的代码**不唤醒就一定不转。

### 4.7 遥测

`T 1` 后每 200 ms（5 Hz）发一行数字，**行尾只有 `\n`**，共 6 个字段：

```text
pos1,pos2,rem1,rem2,arm_us,plt_us
```

含义依次是：升降台累计步数、旋转台累计步数、升降台点动剩余、旋转台点动剩余、机械臂脉宽、载物台脉宽。
可直接喂 `Tools/serial_scope.html` 或 VOFA+。**遥测里没有电机占空比**，看电机要发 `M` / `S`。

### 4.8 报错与回显约定

| 现象 | 含义 |
|---|---|
| `ERR command too long` | 超过 39 字符 |
| `ERR unknown command; send ?` | 前缀没匹配上 |
| `ERR missing value` | 缺参数 |
| `ERR axis is moving; send STOP first` | 运动中改 `LE/RE` 或 `LD/RD`（会丢步/报警） |
| `ERR axis disabled; send LE 1 / RE 1 first` | `LJ` / `LC 1` 前没使能 |
| `WARN n deferred replies dropped` | 轴在连续转，回显排队 4 格满了，丢了 n 条 |
| 回显慢半拍 | 轴运动期间回显会**延迟到停稳后**补发（发脉冲时不允许阻塞串口） |

### 4.9 `PICK` 一键抓取序列

一条命令跑完一轮，**单次执行**。参数全部在 `rig_smoke.c` 顶部的 `RIG_SEQ_*` 区，改动作不用碰状态机。

| 步 | 动作 | 参数 | 结束条件 |
|---:|---|---|---|
| 1 | 夹爪松开 | `A 45` | 等 500 ms |
| 2 | 升降台下降 | `LV 20`、`LD 0`、`LJ 14000` | 步进走完（≈280 ms） |
| 3 | 夹爪夹紧 | `A 73` | 等 500 ms |
| 4 | 升降台上升 | `LV 20`、`LD 1`、`LJ 14000` | 步进走完 |
| 5 | 旋转台顺时针 | `RV 500`、`RD 1`、`RJ 1200` | 步进走完（≈600 ms） |
| 6 | 夹爪松开 | `A 45` | 等 500 ms |
| 7 | 旋转台逆时针 + 载物台同时转 | `RD 0`、`RJ 1200` + `PM 420` | 两轴都停 |
| 8 | 完成 | — | — |

回显（每步一行，按顺序）：

```text
SEQ: start one pick cycle (STOP aborts)
SEQ: gripper -> 45 deg (open)
SEQ: lift down 14000 steps @ 20 us
SEQ: gripper -> 73 deg (close)
SEQ: lift up 14000 steps @ 20 us
SEQ: rotate CW 1200 steps @ 500 us
SEQ: gripper -> 45 deg (open)
SEQ: rotate CCW 1200 steps + platform 420 ms
SEQ: done (one pick cycle)
```

- 序列开始会**自动使能两轴**（`LE 1` / `RE 1`），结束后**保持使能**（不自动释放，避免带载掉落）。
- **开跑前清场**：会中止正在跑的 `GRIP` 流程、载物台角度/`PM` 定时段，并把四路电机全停回待机
  （所以 `PICK` 不会碰底盘电机的输出）。
- `STOP` 随时中止；**任何其它运动命令也会先中止序列再执行**（手动优先）。`S` / `?` / `H` 不算手动命令，
  可以随时查看，`S` 会多打一行 `SEQ state=N running`。
- 每步有 `RIG_SEQ_STEP_TIMEOUT_MS`（10 s）超时；轴没使能、驱动器报警、轴不动都会中止并打印
  `SEQ aborted: <原因>`。
- ⚠ `LV 20` 下 14000 步 ≈ **280 ms**（50 kHz）。先确认 ZDT 跟得上、机构不撞限位再跑。
- 把 `RIG_SEQ_LIFT_PERIOD_US` / `RIG_SEQ_ROT_PERIOD_US` 改慢很多时，记得同步放大
  `RIG_SEQ_STEP_TIMEOUT_MS`。

## 5. 推荐上手顺序（每个执行器先"能不能动"，再"准不准"）

1. **只上逻辑电**：复位后看到 `RIG ready: ...` + 4 行状态；心跳灯 1 Hz 闪。判据：两轴不发热、舵机不出力、轮子不动。
2. **机械臂舵机**：`A 90` → 中位；`A 0` → `A 180` 走全行程；`AO` 掉力矩。判据：平滑、无堵转嗡鸣。
3. **夹爪**：`GRIP` 走完整流程；再 `GRIP H` → `GRIP O`。判据：夹得住、退得开、不持续嗡嗡响。
4. **升降台**：`LE 1` → `LV 2000` → `LD 1` → `LJ 20`。判据：朝一个方向走；反向再点一次。
5. **升降台连续**：`LC 1` → 看几秒 → `STOP`。判据：`STOP` 立刻停，`S` 里 `rem=0`、`pos` 不再涨。
6. **旋转台**：重复 4、5（`RE/RV/RD/RJ/RC`）。
7. **两轴同时**：先 `LC 1`，再在另一个轴发 `RJ 20`。判据：都在动、互不阻塞。
8. **载物台**（换新舵机后再做）：`PU 1500`（应停）→ `P 500`（慢转）→ `P 0` → `Z` → `PT 90`。判据见 4.4。
9. **四路电机（轮子架空、再上 12 V）**：`MM` 核映射 → `M a 250` → `M a 0` → B/C/D 各一遍 →
   `MALL 250` → `MS`。判据：单路指令只有那一路转；`H` 里对应 `CCR` = 2100、`STBY` = 1。
10. **四路序列**：`MR` 跑完或中途 `MS`。判据：1/3/5/7 段分别只有 A/B/C/D；第 9 段不掉压不复位。

## 8. 已知坑（都是真踩过的）

1. **`P <permille>` 不会自己停，`STOP` 也停不了它**：给非零值就一直转，必须 `P 0` 或 `PO`。
   （`STOP` 只停步进与四路电机；只有 `PT`/`PA` 角度运动进行中，它才顺手把载物台回中位。）
   长期堵转就是烧舵机的工况 —— 这也是 2026-10-13 载物台舵机烧坏的可能原因之一。
2. **`PT`/`PA` 的"当前角度"是开环累计值**，不是真实位置；`PV`/`P` 手动转过之后基准就不可信了，
   要用角度先 `PS <deg>` 或 `Z` 重新对零。
3. **短跑目测不能反推角速度**：2026-10-13 把连发 8 条 `P 10` 的**累计** 70° 当成单条，算出 630 °/s
   （真实远没这么快），把 `RIG_PLT_DEG_PER_S` 改错，导致所有命令都跑太短、看起来"完全不动"。
   标速度必须用 5 s 长跑。
4. **`RIG_PLT_DEG_PER_S` / `MIN_RUN_MS` / `MAX_RUN_MS` 是一组**：它们换算成角度 = 时间 × 速度 / 1000，
   改速度不同时看后两个，小角度会被 MIN 抬起来、时间上限也会突然允许转几十圈。
5. **`M` 有回显但轮子不转**：先 `H` 看 `STBY PD2/PD3`，**0 = 待机，一定不转**；再看 12 V 动力电与 VM。
6. **单路不转先排除"命令层"**：`M a 250` 之后 `H` 看 `CCR1` 是否 = 2100。是 → 固件没问题，查接线/驱动/电机；
   否 → 固件或参数问题。
7. **舵机/执行器"完全不动"时**：先分"MCU/PWM 有没有输出"和"执行器坏没坏"——
   `PU 1000`（或 `AU 1500`）之后 `H` 看 TIM9 的 `CCR1/CCR2`，再拿另一路舵机做对照。
   2026-10-13 载物台舵机烧坏那次，就是因为没先分这两件事，白改了一整天代码。
8. **回显"慢半拍"或丢行**：轴在连续转时回显排队 4 格，超了会 `WARN n deferred replies dropped`；正常现象。
9. **`MR` 之前把轮子架空**；第 9 段四路同时转，电源带不动会复位。
10. **心跳灯**：停闪 = 主循环卡住；不亮 ≠ 故障（PC0 本来就不驱动，除非该入口调了 `Led_StatusInit()`）。
11. **`PICK` 运行中发任何其它运动命令都会中止序列**（手动优先，设计如此）；只看状态用 `S` / `H` / `?`。
12. **`PICK` 不会自动释放轴**：跑完两轴仍使能（保持力矩），要断电或 `LE 0` / `RE 0` 才松。
