# 底盘运动层（board_wheel）

**模块**：`BSP/Inc/board_wheel.h` + `BSP/Src/board_wheel.c`
**状态**：代码已完成、编译通过；**台架已实测：直行 / 原地转 / 倒车可用（2026-10-28，经 `WHEEL` Target）**；横移、任务级路径与 `L` 复测仍待实测；默认**不使能**，上电不会自己动。

---

## 1. 它做什么 / 不做什么

| | 内容 |
|---|---|
| **做** | 麦轮逆解算（车体速度 → 四轮目标速度）、每轮速度闭环（前馈 + PI）、输出限幅、软启动、堵转保护、急停 |
| **不做** | 路径规划、"走多远/什么时候走"（那是 App）；里程计/定位（见 `底盘定位设计.md`）；不走 I2C、不发串口 |

**为什么放在 BSP**（`AGENTS.md` 第 2 节）：它回答的是"这套四轮底盘现在是什么状态、怎么驱动它"——
输入是车体速度、输出是四路 PWM，里面没有任何"整车该做什么"的决策。
和 `Motor_Set()`（四路 TB6612）放在同一层是一致的。上层 App 只决定"什么时候、以什么速度走"。

## 2. 控制律与执行时序

```
duty = FF·target + Kp·err + Ki·∫err        （全部整数，Q10 定点，不用浮点）
err  = 本拍目标 counts/s − 实测 counts/s
```

每一个 100 Hz 节拍（TIM7 中断，在 `board_encoder.c` 里）：

```
Encoder_Tick()      采样 4 路计数 → 扩展成 32 位 → M 法算轮速（含低通）→ 写快照
Wheel_Update()      读快照 → 软启动 → PI → 先限幅 → Motor_Set() 写 PWM → 堵转检测
```

`Motor_Set()` 只写寄存器（TIM1 比较值 + 方向脚），可以在中断里调用。
整拍开销约 16 次寄存器写，100 Hz 下可忽略。

**观测点**（供遥测/调参，非阻塞读）：

| 函数 | 单位 | 说明 |
|---|---|---|
| `Wheel_TargetCountsPerSec(id)` | counts/s | 上层下发的目标 |
| `Wheel_OutputPermille(id)` | permille | 本拍实际写出去的占空比（已限幅） |
| `Wheel_State()` | — | `IDLE` / `RUN` / `STALL` |
| `Wheel_StallEvents()` | 次 | 累计堵转次数 |

## 3. 参数区（`board_wheel.h`，改完必须重新编译）

### 3.1 必须先标定的三件事

| 参数 | 含义 | 怎么定 |
|---|---|---|
| `WHEEL_MOTOR_SIGN_A..D` | 电机极性：`+1` = `Motor_Set(id, +permille)` 使该轮朝**编码器正方向**转 | 逐个轮子给正目标，看轮子转向与 `cX` 符号是否一致；不一致改 `-1` |
| `WHEEL_CORNER_A..D` | A/B/C/D 各在哪个角：`0`=左前 `1`=右前 `2`=左后 `3`=右后 | 逐个 `M <x> 300` 看转的是哪个角；编译期会校验这四个必须是 0..3 的一个排列 |
| `WHEEL_FF_PERMILLE_PER_1000CPS` | 前馈：每 1000 counts/s 给多少千分比 | 实测该电压下的最高转速后回填。参考：12V 空载 333 rpm × 22 = 7330 counts/s 对应 1000‰ → **136**（实车 12V 供电，与这条一致）。上板实测预期落在 **130~160**，带载会偏高；用 `Tools/wheel_tune.py` 标定后回填 |

### 3.2 其余参数

| 参数 | 默认 | 说明 |
|---|---:|---|
| `CHASSIS_HALF_LENGTH_UM` / `CHASSIS_HALF_WIDTH_UM` | 110000 / 115000 | 2026-10-27 实测：前后轮心距 220 mm、左右轮距 230 mm → `L = 225 mm`。`L` 是 wz → 轮速的唯一标度，**不影响转到多少度**（航向闭在陀螺仪上） |
| `WHEEL_LATERAL_SIGN` / `WHEEL_SPIN_SIGN` | 1 / 1 | 整机横移/自转整体反向时改 `-1` |
| `WHEEL_KP_Q10` | 200 | 0.195‰ per (counts/s)。震荡减半，反应慢加倍 |
| `WHEEL_KI_Q10` | 8 | 每拍积分增量系数。500 counts/s 误差约 4‰/拍，0.5 s 积到 200‰ |
| `WHEEL_INTEGRAL_LIMIT_PERMILLE` | 300 | 积分限幅（anti-windup 第二道） |
| `WHEEL_DUTY_LIMIT_PERMILLE` | 600 | 输出限幅。**必须明显低于 `Motor_Set` 允许的 1000‰** |
| `WHEEL_TARGET_LIMIT_CPS` | 5000 | 目标限幅 |
| `WHEEL_TARGET_SLEW_CPS` | 400 | 每拍目标最大变化量（软启动，减小打滑与电流冲击） |
| `WHEEL_STALL_CPS` / `WHEEL_STALL_MS` | 80 / 600 | 堵转判据；`0` = 关闭 |

`WHEEL_CTRL_HZ` 直接跟随 `ENCODER_TICK_HZ`（100 Hz），不另开定时器。

## 4. 安全设计（按 `AGENTS.md` 第 6 节控制环要求）

1. **默认不使能**：`Board_Init()` 里只调 `Wheel_Init()`，`enabled = 0`，
   `Wheel_Update()` 第一句就返回 → **上电四路输出保持 0**，生产固件行为不变。
2. **输出先限幅再写 PWM**，且限幅 600‰ 远低于 1000‰。
3. **anti-windup**：积分限幅 + 条件积分（输出顶到限幅且误差同向时不再累加）。
4. **软启动**：目标按每拍 400 counts/s 逼近，避免阶跃打滑。
5. **堵转保护**：输出顶到限幅 + 实际几乎不动 + 目标要得更多 → 持续 600 ms 则急停并置 `STALL`。
6. **急停可重入**：`Wheel_Stop()` 内部关中断清状态，会被 ISR 调用；含"ISR 里也能安全执行"。
7. **使能时先唤醒 TB6612**：`Motor_StopAll()` 会把两片压回待机（`AGENTS.md` 第 11 节记着这个坑），
   所以 `Wheel_Enable(1)` 里先 `Motor_Standby(0/1, 1)`，否则写了 PWM 电机也不动。
8. **目标为 0 时直接断电**并清积分，避免"给了 0 还在转"。

## 5. 台架调参步骤（WHEEL 入口已接通；标定主体已完成，遗留项见第 6 节）

> **进度（2026-10-28）**：下面 1~5 已完成并写回参数区（定案过程见
> [速度环调参与里程计](速度环调参与里程计.md) 2026-10-26/27 条）；第 6 步的直行与
> 自转已实测可用（2026-10-28），**横移方向仍未确认**（`B 0 300000 0` 只有两轮动、
> 走斜线的问题还没查掉），`ML`/`MR`/`TASK`/`LAP` 待实测。

`WHEEL` Target 已调用速度环接口，默认仍失能；命令及遥测见 [速度环调参与里程计](速度环调参与里程计.md)。上板顺序：

1. **定电机极性**：`E 1` 使能 → 给 A 轮 `+500 counts/s` → 看轮子是否朝"正转"、`sA` 是否为正；
   不符改 `WHEEL_MOTOR_SIGN_A`。
2. **定角映射**：四轮分别给正目标，记下各自在哪个角 → 填 `WHEEL_CORNER_*`。
3. **定前馈**：把 Kp/Ki 设 0，给定几个目标值，记录稳态占空比 → 线性拟合出
   `FF = 1000 / (每 1000‰ 对应的 counts/s)`。
4. **调 Kp**：前馈对了以后加 Kp，从 100 起，翻倍到出现小幅震荡再退回一半。
5. **调 Ki**：加 Ki 消稳态误差，从 4 起；出现低频摆动就减。
6. **验整机**：`B vx 0 0` 应直行；`B 0 vy 0` 应横移；`B 0 0 wz` 应原地转。
   方向不对改 `WHEEL_LATERAL_SIGN` / `WHEEL_SPIN_SIGN`，单轮不对改该轮 `WHEEL_MOTOR_SIGN_*`。
