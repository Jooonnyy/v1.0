## 推荐步骤

### 1. 无动力检查

1. 断开电机和舵机动力电源，只保留逻辑电源、SWD 和需要的串口。
2. 测量 3.3 V、5 V 与各动力电源，确认所有电源共地。
3. 下载生产固件，确认复位后**失能 + 不发脉冲**：三根 nEN（PD3 四轮、PC8 旋转、PC9 升降）都是高、
   六路 STEP（PE9/PE6/PA0/PB0/PD12/PA6）没有方波、六路 DIR 为低；舵机 PB14/PB15 没有脉冲。
   （2026-11-09 更新：这一版是新底板 V2 的引脚；老板那套 TB6612 STBY / DRV8825 nEN / PA7 舵机
   已经不适用，见 `Docs/PINMAP.md`。2026-10-27：ULN2003 驱动已删除，PE1～PE4 上电为浮空。）
4. 通过 USART1 验证 `HELP` 与 `STATUS`，暂不发送动作命令。

### 2. 无机械运动的链路

先验证 `HMI`。屏端必须已经存在两个页面：第 0 页 `t0`/`t1`（任务码）、第 1 页 `t2`/`t3`（统计），波特率设为 115200；烧录 MCU Target 不会把界面工程下载到屏。`HMI` Target 现在还会从 USART3（PC10/PC11，115200）读取树莓派的 `TASK` / `STAT` 命令，屏工程与联调步骤见 [串口屏任务码显示](串口屏任务码显示.md)。（**2026-10-27**：`TOF` / `MPU6050` 单项 Target 已删除；两者共用 PB6/PB7 的硬件核对结论仍有效，历史文档已于 2026-11-17 清理。）

### 3. 四路底盘电机（开环）

架空四个车轮，手离开机构。**2026-10-27**：`Motors_PowerOn` / `Motors_All` / `Motor_C`
三个单项 Target 已删除，四路电机开环测试统一用 **`RIG`**（蓝牙，或临时接 USART2 的 USB-TTL）：

- 发 `MR` 才跑那条 12 段序列，`M a 250` 单路驱动、`M c 0` 只停一路、`MALL 250` 四路一起、
  `MS` / `STOP` 全停，上限 250‰，`H` 能直接看 STBY 电平。命令与判据见 [蓝牙联调](蓝牙联调_升降台旋转台机械臂载物台.md) 第 3.5 节。
- 旧 Target 的验证记录已随历史文档清理（2026-11-17）。

**不想让它上电就动**：`RIG` Target（蓝牙联调）从 2026-10-11 起也带同一套四路电机开环命令——
发 `MR` 才跑那条 12 段序列，`M a 250` 单路驱动、`M c 0` 只停一路、`MALL 250` 四路一起、`MS` / `STOP` 全停，
上限同样是 250‰，`H` 还能直接看 STBY 电平。命令与判据见 [蓝牙联调](蓝牙联调_升降台旋转台机械臂载物台.md) 第 3.5 节。

A 路此前已在实板上确认可转（2026-09-24），但当时的记录没有覆盖编码器。单独复看某一路用 `RIG` 的 `M a 300`。

### 4. 四路底盘闭环与定位（`WHEEL`）

这一步依赖编码器计数与方向符号核对。**2026-10-27 起 `ENCODER` 单项 Target 已删除**，该核对直接在 `WHEEL` 里做：`N` 打印四路累计计数（手转减速箱一圈约 1320），`CMP [permille] [ms]` 四路依次开环对比稳态转速。`WHEEL` 上电**不使能轮子**、默认不开遥测，必须先发 `E 1` 再下发目标。最省事的调参路径是 `X <轮> <counts/s> [ms]`（闭环阶跃，只回一行摘要）和 `D <轮> <permille>`（开环占空比，用于把"电机没转"和"编码器没反馈"分开）。命令、遥测通道和七项标定实验见 [速度环调参与里程计](速度环调参与里程计.md)。

⚠ `WHEEL` 的 PID 与几何参数目前全是占位值，**不能据编译通过宣称已调好**；`X` 回 `peak=0 steady=0` + `STALL` 时先怀疑编码器没反馈，不要先怀疑 PI。

### 5. 舵机

**2026-10-27**：`Servo` 单项 Target 已删除，舵机调试用 `RIG` 的 `A <us>`（机械臂 U5 / PA7 默认，或开关置 0 时 PE5）与载物台 U6（PE6）相关命令，标定方法见 [舵机验证](舵机验证.md)（历史记录）与 [蓝牙联调](蓝牙联调_升降台旋转台机械臂载物台.md)。

### 6. 蓝牙联调（`RIG`）

升降台、旋转台、两路舵机、四路电机一次接齐的蓝牙文本命令联调，上电不自动运动（复位后**板载 PC0 LED 以 500 ms 心跳闪烁**，可用来确认固件在跑；注意它与电源指示灯无关）。按 [蓝牙联调](蓝牙联调_升降台旋转台机械臂载物台.md) 第 4 节的 10 步判据执行（先只给逻辑电，再逐个执行器）。⚠ 蓝牙链路没有断线检测，**不能用蓝牙代替硬件急停**。

### 7. U1 升降和 U4 步进（对应单项 Target 已删除）

`Lift_U1` / `Stepper_42_U4` 已于 **2026-10-27 删除**。升降台 / 旋转台现由 `RIG` 的两轴 ZDT（闭环步进，LIFT / ROT）覆盖；`board_lift.c`（DRV8825 版）保留在 BSP 但当前无调用入口（链接期 GC 丢弃）。

### 8. 28BYJ-48 与 ULN2003（对应 Target 已删除）

`Stepper_28`、`Stepper_Phase`、`Stepper_Example10`、`Stepper_Example10_Slow` 四个 Target 已于 **2026-10-02 删除**：实板上三种相序、两档速度都只看到"震动、输出轴不转"，没有形成连续转动的通过记录，继续保留只是重复同一个结论。

⚠ 原理图把 M2 的 `+` 接到 **12 V**，而常见 28BYJ-48 是 5 V 型；重新做这项验证前必须先解决供电，不要直接复用当时的接法。

### 9. 其余功能

B/D 电机、四路编码器、传感器和树莓派串口没有完整实板记录，不应直接加入生产动作流程。

### 10. 生产固件

单项验证完成后烧录 `Vehicle_Integrated`。先无动力验证命令，再依次测试 A 路和夹爪。当前生产应用不会驱动步进电机、B/C/D 电机或 HMI。
