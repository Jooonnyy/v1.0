# 自研一体板 V3：方案（参考国赛特等奖工程后修订）

> 2026-11-13。已通过嘉立创 EDA 桥读取当前工程 `gshwww5/工创赛全国总决赛_copy`（5 块板）。
> 本文在已确认的 **12V 单电源、6 路闭环外置、100×100、单板** 前提下，
> 吸收参考工程的电源与接口做法，给出可落地的 V3 方案。
>
> 事实来源：参考工程 PCB 焊盘网表（本次实时读取）、`Docs/交接文档_新底板V2.md`、
> `Docs/新板引脚分配_6路步进.md`、`Docs/舵机验证.md`（MG90S）。

## 0. 结论

**能合并，而且参考工程已经把这条路走通了。**

- 参考工程的 **上部控制板 70×65 mm** 里放下了：F407VET6 芯片直贴、5 路 ZDT 步进接口、
  4 路舵机、6 路串口、USB-C、WiFi 座。你的 **100×100 = 10000 mm²** 是它（4550 mm²）的 2.2 倍，
  还要多放电源——面积够，但没有想象中富余。
- 参考工程的 **分电板** 是 3S 11.1V 输入，两路 5A 降压出 **7.4V / 5V**，
  11.1V 直接经 XT30 分给各板。这正是“单电源进、多路出”的成熟做法。
- **唯一不能照抄的是舵机电压**：参考板用 7.4V，因为它配的是高压舵机；
  你用的是 **MG90S（4.8~6V）**，必须出 **6V**，否则烧舵机。

一句话：**V3 = 参考板上部控制板的接口 + 参考板分电板的电源，合进一块 100×100 的 4 层板；
舵机降压改 6V，ZDT 接口从 8P 扩到 10P（补 EN/ALM）。**

## 1. 参考工程拆解（这次实际读到的）

### 1.1 五块板的分工

| 板 | 板框 | 核心器件 | 作用 |
|---|---|---|---|
| 底盘控制专用板 | — | **STM32F407VET6**、CAN 收发器、RS232 收发器、4 路舵机、6 路串口 | 无刷底盘、全图定位、CAN/232 外设 |
| **上部控制板** | **70×65 mm** | **STM32F407VET6TR**、CH552G、5× ZDT 8P、4 路舵机、6 路串口、WiFi 座 | 执行机构 + 总控；和你的板最像 |
| **分电板** | **70×65 mm** | 2× TO-263-5 5A 降压、47µH、SS54、470µF、6× XT30 | 3S 11.1V → 7.4V / 5V / 11.1V |
| 直流电机板 | — | STM32F103（LQFP48）、2× ESOP-8 驱动、电流采样、编码器接口 | 直流电机 + 编码器 + ADC |
| 视觉转换板 | — | XT30 + USB-A + 滤波 | 给 USB 相机供 5V |

### 1.2 分电板的电源树（从焊盘网表反推）

```
CN1 XT60 11.1V ──┬── 11.1V 母线 ── CN4 / CN5 / CN6（3× XT30 输出）
                 │
                 ├── U5（TO-263-5，5~32V/5A，300kHz）+ L1 47µH + D5 SS54
                 │      └── 7.4V ── CN7（XT30 输出）
                 │
                 └── U6（同型号）+ L2 47µH + D6 SS54
                        └── 5V ── CN2 / CN3（2× XT30 输出）
```

- 输入、输出全部用 **XT60 / XT30**，没有排针；
- 每路输出 **470µF/35V**，二极管 **SS54（40V/5A）**，电感 **47µH/5A**；
- 两路反馈分压独立，输出 7.4V 与 5V；
- 板子是 **2 层**，功率环路短、铜皮厚。

### 1.3 上部控制板的 ZDT 接口（重点）

5 个 **XH2.54-8P** 卧贴座，每个座的焊盘网络是：

| 脚 | 网络 | 含义 |
|---|---|---|
| 1 | 12V | 驱动器电源（来自分电板 11.1V） |
| 2 | GND | 地 |
| 3 | GND | 地（双地，分流） |
| 4 | 3V3 | 3.3V 参考/逻辑 |
| 5 | A5 / A7 / D11 / D9 / E1 | 信号 1（脉冲或 EN） |
| 6 | A4 / A6 / D10 / D8 / E0 | 信号 2（方向或 ALM） |
| 7 | RS485A | 全部并联 |
| 8 | RS485B | 全部并联 |

**一个座同时带电源、脉冲、RS485**——一根 8P 线接到驱动器，不用再单独拉电源。
RS485 A/B 是总线式，5 个驱动器共用，由一颗 **RS485 隔离收发器** 驱动。

### 1.4 其它可直接复用的电路

- **F407 最小系统**：8MHz 晶振 + 2×20pF、NRST 10k+100nF、BOOT0、VCAP、每脚 100nF、
  VDDA 磁珠、SWD 4P、USB-C + ESD。参考板已经验证过，照抄即可。
- **USB 转串口**：参考板用 **CH552G**（SOP-16，需自带固件）；你用 **CH340N** 更省事，
  引脚和 USART1 接法一样，固件不用改。
- **3.3V**：每块板本地一颗 SOT-23-5 LDO（5V→3.3V），不跨板送 3.3V。
- **舵机**：4 路 3P（MXPH-2.0），每路并 **120µF**，整板 470µF；信号直接进 TIM4_CH1~4。
- **CAN**：SOIC-8 收发器 + 120Ω 终端 + 2P 座；**RS232**：SOIC-16 收发器。
  你的车没有这两样，不用抄。
- **层数**：控制板 4 层（用了 Inner1 走线），分电板 2 层。合并后建议 4 层。

## 3. 你的 V3 方案

### 3.1 总体

| 项 | 规格 |
|---|---|
| 形态 | 单板：主控 + 电源 + 6 路 ZDT 接口 + 2 路舵机 + 5 路串口 |
| 尺寸/层数 | **100×100 mm，4 层**（信号 / GND / 电源 / 信号），1.6 mm，1~2 oz |
| 主电源 | **XT60，3S 11.1V（9.0~12.6V）**；兼容 12V 铅酸（10.5~14.4V） |
| 输入保护 | 20A 片式保险丝 → P-MOS 防反 → SMBJ18A → 470µF/35V |
| MCU | STM32F407VET6（LQFP100），8MHz，SWD，USB-C + CH340N |
| 驱动器 | 6× **XH2.54-10P**：12V/GND/GND/3V3/STEP/DIR/EN/ALM/RS485A/RS485B |
| 舵机 | 2× 3P，**6V** 独立降压，每路 220µF + 220Ω + TVS |
| 串口 | 5× 4P：调试（USB/CH340）、陀螺、树莓派、串口屏、蓝牙 |
| 其它 | Pi 5V 2P、I2C 4P、限位 3×2P、按键 2P、补光灯 2P、SWD 4P |

### 3.2 电源树

```
XT60 11.1V ──[20A 保险丝]──[P-MOS 防反]──[SMBJ18A]──[470µF/35V]──┬── 6× ZDT 10P（每座 100µF/25V + 100nF）
                                                                  │
                                                                  ├── 6V/3A 降压（LM2596/XL4015，47µH，SS54）
                                                                  │      └── 2× MG90S（各 220µF + 220Ω/TVS）
                                                                  │
                                                                  ├── 5V/1A 降压（LM2596-5.0）── 屏/蓝牙/陀螺/CH340
                                                                  │
                                                                  ├── 5V/3A 同步降压（LMR33630/TPS54360B）── 树莓派
                                                                  │
                                                                  └── 5V→3.3V LDO（AMS1117-3.3）── MCU/陀螺/I2C
```

**为什么这样分：**

- **11.1V 直供 6 路 ZDT**，和参考板一样，不经过 buck；
- **6V 单独一路**给 MG90S，参考板的 7.4V 不能抄；
- **Pi 单独同步降压**：Pi 启动 3A，LM2596 在 12V→5V/3A 时耗散约 4W，TO-263 会烫；
  逻辑 5V 只有 1A，用 LM2596 没问题；
- **3.3V 用 LDO**：0.3A，压差 1.7V，耗散 0.5W，和参考板一致；
- 电容全部 35V 耐压，给以后换 24V 留余量（那时只换保险丝/TVS）。

### 3.3 ZDT 10P 接口定义（在参考 8P 上补 EN/ALM）

| 脚 | 网络 | 说明 |
|---|---|---|
| 1 | 11.1V | 驱动器电源 |
| 2 | GND | 地 |
| 3 | GND | 地（双地） |
| 4 | 3V3 | 3.3V 参考 |
| 5 | STEP | 脉冲（A/B/C/D/ROT/LIFT 各一根） |
| 6 | DIR | 方向（PE7/PE8/PE10/PE12/PE13/PE14） |
| 7 | EN | 使能（PD3 四轮共用；PC8 旋转；PC9 升降） |
| 8 | ALM | 报警，六路开漏线或到 PD4，10k 上拉 |
| 9 | RS485A | 总线，预留 |
| 10 | RS485B | 总线，预留 |

> 参考板的 8P 只留了两根信号，因为它用 RS485 或两根线就够；你需要 EN 和 ALM，
> 所以扩到 10P。**引脚顺序尽量按上表固定**，以后换线不会插错。

### 3.4 引脚：照抄 V2，只加不改

V2 as-built 的 44 个脚原样保留，固件零改动。新增只用空闲脚：

| 新增 | 引脚 | 说明 |
|---|---|---|
| I2C1 SCL/SDA | PB6 / PB7 | 4.7k 上拉到 3.3V |
| 限位 ×3 | PD6 / PD7 / PD8 | 10k 上拉 + 100nF + 1k 串阻 |
| nFAULT 汇总 | PD4 | 六路 ALM 开漏线或 |
| 电池电压 | PA4 | 分压 1/11，ADC1_IN4 |
| 总电流 | PA5 | ADC1_IN5，霍尔或 INA240 |
| RS485（可选） | PE0 / PE1（UART8） | 空闲，留给将来 ZDT 总线 |

### 3.5 100×100 面积预算（按 10P 座）

| 区域 | 估算 | 面积 |
|---|---|---|
| 6× XH2.54-10P（27.5×10.5） | 2+2+2 分三边 | ~1730 mm² |
| 电源区（XT60/保险丝/防反/3 路 buck/电感/电容） | 45×40 | ~1800 mm² |
| MCU 最小系统（LQFP100 + 晶振 + 阻容） | 30×30 | ~900 mm² |
| 5 串口 + 2 舵机 + Pi + 屏 + 限位 + I2C | — | ~1200 mm² |
| 安装孔、边距、走线通道 | — | ~2500 mm² |
| **合计** | | **~8130 / 10000 mm²** |

参考板在 4550 mm² 里放 5 路 ZDT + 4 舵机 + 6 串口 + MCU；你 10000 mm² 放 6 路 10P + 电源，
是够的，但 6 个 10P 座占边很长，必须 **2+2+2 分三边**，不要排一条边。

### 3.6 布局顺序

1. 板框 + 4× M3 孔（孔边距 ≥3mm）。
2. **XT60 + 保险丝 + 防反 + 3 路 buck 固定在左上角**，功率环路缩在 45×40 内。
3. **6 个 10P 座 2+2+2 分在左、右、下三边**，每边 55mm，中间留安装孔。
4. MCU 放板中央，晶振/USB 远离电感和 11.1V 主干。
5. 5 路串口、USB-C、SWD 排上边；舵机、Pi、屏、限位排右下。
6. 去耦最后放，贴引脚。

层叠：

```
L1  信号 + 器件
L2  完整 GND
L3  11.1V / 6V / 5V / 3.3V 分区电源
L4  信号 + 低速接口
```

## 4. 从参考工程学到、但必须改的地方

### 4.1 舵机 7.4V ≠ 你的 6V

参考板上部板 4 路舵机全部接 **7.4V**，每路并 120µF。它用的是高压舵机。
你的 `Docs/舵机验证.md` 写明是 **MG90S**，额定 4.8~6V。**直接接 7.4V 会烧。**
V3 的 6V 降压反馈电阻按 6V 配（LM2596：R1=1k、R2=3.9k 约 6.0V），
并在丝印上写死 `6V ONLY`。

### 4.2 3S 11.1V 不是 12.0V

参考板所有网络名都是 **11.1V**，满电 12.6V。你说的“12V”如果是 3S 锂电，
输入范围就是 9.0~12.6V；如果是 12V 铅酸，是 10.5~14.4V。
V3 按 **9~14.4V** 设计，保险丝 20A、TVS SMBJ18A、电容 35V，两种都覆盖。

### 4.3 ZDT 的 RS485 是“备胎”，不是主路径

参考板把 5 个 ZDT 的 RS485 A/B 全并联，用一颗隔离收发器驱动，说明它可能用总线控制。
你的固件是 6 路独立定时器发脉冲，**V3 先按脉冲走**，RS485 只布线、不焊收发器；
将来想省定时器/省线，再在 UART8（PE0/PE1）上实现 ZDT RS485 协议。
**不要为了 RS485 改现在的固件。**

### 4.4 5 路 ZDT 的 8P 座别直接换成 6P

V2 的 6P 只带 12V/GND/COM/EN/STEP/DIR，没有 ALM、没有 RS485、没有 3.3V 参考。
参考板的 8P 把电源、信号、总线合并到一根线，接线和防呆都好。
V3 用 10P 是它的超集，**线束按 10P 重新压**，不要混用 V2 的 6P 线。

### 4.5 参考板的 70×65 是“极限密度”

参考板上部板 70×65 mm 放 74 个器件，已经非常密。你 100×100 虽然面积大，
但多了电源区（1800 mm²）和 6 个 10P 座（1730 mm²），实际余量约 1900 mm²。
**布局时先放连接器和电源，再放 MCU**，不要先画 MCU 再塞连接器。

## 5. 固件影响

- 引脚表照抄 V2 → `stepper6.h`、`board_step6.c`、`board_comm.c` 不动。
- USB 从 CH552G 换 CH340N，**电脑端仍是 COM 口 + USART1**，不用改。
- 新增功能才加 BSP：限位、电流/电压采样、nFAULT、I2C。
- RS485 预留不实现；将来用 UART8（PE0/PE1），要加 ZDT 协议解析。
- 按键仍 PB3、LED 仍 PC0，避免改 `board_gpio.c`。

## 7. 上电顺序

1. 只焊电源：限流 300mA，测 11.1V / 6V / 5V / 3.3V，纹波 <50mV。
2. 焊 MCU：SWD 能连、读 ID。
3. 烧录点灯，USART1 出字符。
4. 示波器看 6 路 STEP（不接驱动器）。
5. 逐轴接 ZDT，点动确认方向/使能/ALM。
6. 接 MG90S（先量 6V），再接屏、Pi、陀螺。
7. 满载 10 分钟：测 11.1V 入口压降、buck 温升、10P 座温升。

## 8. 还需要你确认的 3 件事

1. **电池到底是 3S 锂电还是 12V 铅酸？** 这决定输入范围（9~12.6V 还是 10.5~14.4V）
   和低压报警点。
2. **MG90S 是否换成高压舵机？** 如果以后要换 7.4V 舵机，6V buck 的反馈电阻要留两个焊盘。
3. **ZDT 用脉冲还是 RS485？** 现在按脉冲；如果要走 RS485 总线，UART8 和隔离收发器要提前布局。
