# 新底板 PCB 布局布线要点

> 依据 2026-10-29 08:23 抓取的网表（工程 `gswwww5/STEP` / 板 `电控板`）。改过原理图后要重新核一遍。
> 这份是布线期的操作清单，不是设计规范文档。

---

## 1. 分区（先定这四条线）

```
┌─────────────────────────────────────────────────────────┐
│  XT30 12V ─┬─ 12V 主干（≥3mm） ──────────────────┐      │
│  CN1 6P   ─┘                                      │      │
│                                                   ▼      │
│  ┌──────┐ ┌──────┐ ┌──────┐   ┌────────┐   ┌──────┐     │
│  │ M_A  │ │ M_B  │ │ M_C  │   │ 核心板  │   │ 屏   │     │
│  └──────┘ └──────┘ └──────┘   │ FK407  │   │ 4P   │     │
│  ┌──────┐ ┌──────┐ ┌──────┐   │  插座   │   └──────┘     │
│  │ M_D  │ │ 旋转 │ │ 升降 │   └────────┘   ┌──────┐     │
│  └──────┘ └──────┘ └──────┘                │ Pi 4P│     │
│      功率区（粗线/大电流）      逻辑区        └──────┘     │
└─────────────────────────────────────────────────────────┘
```

功率区（12V、6 个驱动器接口、电机出线端子）和逻辑区（核心板、屏、Pi、HWT101、按键）在物理上分开，
中间只留 12V→5V 和信号跨越。**不要**让电机线从核心板底下穿过。

## 2. 摆放顺序（按约束从强到弱）

1. 板框 + 4 个 M3 孔（孔边距 ≥3mm，孔周围禁布区 ≥1mm）
2. **核心板插座**——这是最硬的约束，先定它。SWD 排针和 USB 口朝板边，插上核心板后还能下载/插线
3. **6 个驱动器接口**（A/B/C/D/旋转/升降）沿功率区板边排开，每组旁边留电机出线端子
4. **XT30 + CN1 + 4 个 SS12D00 开关**集中在功率区一角，人手指能直接拨到
5. 屏、Pi、HWT101、按键接口排在逻辑区另一边
6. 去耦电容最后放，但**必须贴着**器件引脚

## 3. 六个驱动器接口的防呆

六个接口都是同一型号，**一定插得反、一定插得错轴**。三条措施至少做两条：
- 丝印大字标 `A / B / C / D / ROT / LIFT`，并且每个轴的 `STEP`、`DIR` 单独标在焊盘旁
- 相邻两轴用不同颜色排针，或把 1 脚做成方形焊盘并加三角标记
- 每个接口旁边留 **STEP 测试点**（1.5mm 焊盘），以后要示波器看波形，没测试点只能拿探针戳排针

## 4. 电源与地

| 走线 | 最小宽度（2 层 1oz） | 说明 |
|---|---|---|
| 12V 主干 | **3 mm**（或 2mm 并开窗加锡） | 6 轴峰值约 9A，2mm 只有约 5A |
| 12V 支线（每轴） | 1.5 mm | |
| 舵机 5V | 1.5 mm | 堵转瞬时 2~3A |
| 逻辑 5V / 3.3V | 0.6 mm | |
| 信号 | 0.25 mm | |

- **整板铺 GND**，但功率地和逻辑地**分区铺、单点汇合**：汇合点放在 XT30 附近，用 0Ω 电阻或磁珠跨接，别让电机回流电流横穿逻辑区地平面。
- 12V 入口加 **自恢复保险丝（3~5A）+ 反接保护**（PMOS 或肖特基），现在网表里没有。
- **每个驱动器 V+/GND 引脚旁 3mm 内**放 100µF 电解 + 100nF 瓷片。现在整板只有 C4/C8 两颗挂在 12V 上，六个驱动器分不到。
- 12V 主干从 XT30 出来后**先经过电容再分叉**，不要从中间节点抽头。

## 5. 信号走线

**STEP/DIR（6 组）**
- 每组 STEP 和 DIR 可以并排走，线间距 ≥3 倍线宽
- **禁止**与 12V 主干长距离并行（>20mm）；必须交叉时垂直过
- 六组不要并成一大束，按轴分组走，各自靠近自己的驱动器

**舵机（PB14/PB15）**
- 信号线 MCU 端串 **220Ω**（贴近 MCU），TVS 贴近连接器
- 舵机电源线和信号线分开走，不要平行
- 5V_SERVO 的 470µF 贴着舵机连接器

**串口（屏 PC6/PC7、Pi PC10/PC11、陀螺 PA2/PA3）**
- 每组 TX/RX 可以并走，串 33~100Ω 可选（长线/跨板时加）
- 串口线远离 12V 和 STEP 线

**I2C（PB6/PB7）**
- 板上补 **4.7k 上拉到 3.3V**（现在没有）
- I2C 是开漏弱驱动，走线尽量短，别绕板一圈

**晶振/复位**
- 核心板是插上去的，**插座正下方不要走线、不要打过孔**，铺铜也要挖开

## 6. 布局完成后、投板前必须做的

1. **DRC 全过**（线宽、间距、孔径、丝印压焊盘）
2. 对一遍网表：MCU 每个脚的网络与原理图一致，特别是六个 STEP 和六路 DIR
3. 检查 12V 和 GND 之间**没有短路**（用万用表二极管档量，投板前查一次 Gerber 也值得）
4. 电源入口极性、丝印 `+12V` / `GND` 是否标清
5. 板边留 1mm 以上无铜区，方便 V-CUT/铣边

## 7. 还没画的（布线时顺手留位置）

| 缺的东西 | 建议位置 |
|---|---|
| 底盘四路 EN | 一根线并到 PD3，4 个接口的 pin4 都接它 |
| 机械臂限位/原点 ×2 | PD8、PD9，各留 2P 座 + 10k 上拉 + 100nF |
| 蓝牙串口 | UART5：PC12=TX、PD2=RX，4P 座（5V/GND/TX/RX） |
| 电机总电流采样 | PA4/PA5 留分压+采样电阻位，不焊先留着 |
