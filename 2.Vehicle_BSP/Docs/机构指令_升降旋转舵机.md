# 机构指令：升降台 / 旋转台 / 舵机 / CYC

> **2026-11-09。** 新底板 V2 上，升降台、旋转台、两路舵机、以及 `CYC` 任务循环
> 第一次有了生产固件入口。全部是**开环**控制，**尚未上板验证**。
> 引脚事实见 `Docs/PINMAP.md` §1；参数区在 `App/Inc/pick_config.h`。

## 1. 这四样东西分别是谁

| 名称 | 执行器 | 引脚 | 驱动层 |
|---|---|---|---|
| 升降台 | 张大头闭环步进（STEP/DIR） | STEP PA6 / TIM13_CH1，DIR PE14，nEN **PC9** | `Step6_*`（`STEP6_LIFT`） |
| 旋转台 | 张大头闭环步进（STEP/DIR） | STEP PD12 / TIM4_CH1，DIR PE13，nEN **PC8** | `Step6_*`（`STEP6_ROT`） |
| 夹爪 / 机械臂 | 位置舵机 U5 | **PB14** / TIM12_CH1，50 Hz | `Servo_SetPulseUs()` |
| 载物台 | 连续旋转舵机 U6 | **PB15** / TIM12_CH2，50 Hz | `Servo2_SetPulseUs()` |

代码分层：驱动在 `BSP/`（`board_step6.c`、`board_motion.c` 的 `Servo_Init()`），
跨器件编排在 `App/Src/pick_app.c`，命令解析仍在 `App/Src/vehicle_app.c`。

## 2. 命令（全部是"点动距离"）

| 命令 | 参数 | 走多**远** | 走多**快**（可选） | 需要 `E 1` | 回显 |
|---|---|---|---|---|---|
| `ROT` | `<deg> [hz]` | **角度** ±360（不能 0） | 第二个参数，默认 `PK_ROT_HZ` = 2000 | **是** | `OK ROT 90 deg (800 pulses @ 2000 Hz)` → `ROT done, 800 pulses, 400 ms` |
| `LIFT` | `<pulses> [hz]` | **脉冲数** ±`PK_LIFT_MAX_PULSES` | 第二个参数，默认 `PK_LIFT_HZ` = 30000 | **是** | `OK LIFT 8000 pulses @ 30000 Hz` → `LIFT done, 8000 pulses, ~350 ms` |
| `LIFT HOME` | `[hz]` | **回起点**：按累计位置的反向走回去 | 同上 | **是** | `OK LIFT home, -6000 pulses` → `LIFT done, ...` |
| `LIFT ZERO` | — | 把当前位置定义成原点（手动开到最高处后对齐用） | — | 否 | `OK LIFT zero, pos=0` |
| `LIFT ?` | — | 查累计位置 | — | 否 | `LIFT pos=-6000 pulses` |
| `ARM` | `<deg>` 或 `OFF` | **角度** 0..180° → 1000..2000 µs | —（位置舵机自己走） | 否 | `OK ARM 130 deg (1722 us)` / `OK ARM off` |
| `PLT` | `<ms>` 或 `OFF` | 连续旋转舵机**没有位置反馈**，只能按**时间**：转 `ms` 毫秒后自停 | 固定 `PK_PLAT_JOG_PERMILLE` = 400‰（40%），负毫秒 = 反方向 | 否 | `OK PLT 400/1000 for 413 ms` → `PLT done, stopped` |
| `CYC` | `[n]` | 连跑 n 轮正式任务：降 → 夹 → 升 → 转 → 松 → 盘走一格 → 转回（默认 `PK_CYC_ROUNDS_DEFAULT` = 3） | — | **是** | `CYC start, 3 rounds (STOP aborts)` … `CYC done (3 rounds)` |
| `TRG` | `[n]` | 卸料 n 轮：载物台夹起 → 降到地面 → 松开 → 升回最高处（默认 1 轮） | — | **是** | `TRG start, 1 rounds (STOP aborts)` … `TRG done (1 rounds)` |
| `GRAB` | `<cls> [tol_mm] [HOLD]` | 视觉追踪锁定后取料；**默认抓完顺手放到载物台**（转 -132° → 松开 → 盘走一格 → 转回），`HOLD` 只夹不放 | — | **是** | `GRAB start, pick then place (STOP aborts)` … `GRAB done, placed, held at top` |
| `PLACE` | — | 手里夹着料、停在最高处时，只做放料那半段 | — | **是** | `PLACE start, turn-open-step-back (STOP aborts)` … `PLACE done, held at top` |
| `DROP` | `[n]` | 圆环放置：**顶部粗对 → 下降 → 底部精对 → 取料 → 转回放料侧 → 松开**（精对后底盘不动）；n=1..9，默认 1；起点最高处、载物台有料 | — | **是** | `DROP start ring 2: align empty, then pick+place (STOP aborts)` … `DROP done, ring placed` |
| `HINT` | `<cls>` | 只把类别下发给树莓派（USART3 的 `$C,<cls>`），不动电机 | — | 否 | `OK HINT cls=3, sent $C` |
| `IN` | — | 读输入口电平：`key/top/bottom/home`（确认上限位有没有接/压到） | — | 否 | `IN key=1 top=0 bottom=0 home=0` |
| `TASK` | `<code>` 或空 | 带 15 位任务码：只上屏（page 0 的 `t0/t1`），不启动路线；不带参数：原路线启动 | — | 否 | `OK TASK` / `ERR TASK FORMAT` |
| `STAT` | `<g> <p>` | 抓取/放置正确次数上屏（page 1 的 `t2/t3`），0..999 | — | 否 | `OK STAT` |
| `SCAN` | — | 往树莓派发 `@SCAN`，通知它到扫码区扫码 | — | 否 | `OK SCAN` |
| `STOP` | — | 停底盘 + 两轴 + 载物台，中止 `TASK` / `CYC` / `TRG` | — | — | `CYC aborted: STOP` + `TRG aborted: STOP`（若在跑）+ `OK stopped` |
| `E 0` | — | 三根 nEN 一起断，同时中止 `CYC` / `TRG`、收回载物台 | — | — | `OK disabled` |

`S` 现在多打几行：`ROT hz/dir`、`LIFT hz/dir`、`SERVO arm/plt`、`CYC on|off round=k/n  TRG on|off  GRAB on|off  DROP on|off`。

`CYC` / `TRG` / `DROP` 跑的时候，`LIFT` / `ROT` / `ARM` / `PLT` 的手动命令会被拒绝（回
`ERR sequence running, send STOP`），`ARM OFF` / `PLT OFF` 仍然放行。
四者互斥：一个在跑时发另一个会回 `ERR ... running, send STOP`。

### 2.1 单位怎么选（为什么不是"速度 × 时间"）

- **旋转台**：角度天然是距离 → 换算成 `${角度} × PK_ROT_PULSES_PER_REV / 360` 个脉冲，走完自停。
- **升降台**：给**脉冲数**。没有丝杆导程的实测值，mm 无从谈起，脉冲是最诚实的单位；
  知道导程后按 `导程_mm ÷ 3200 × 脉冲数` 换算即可（见 §7）。
- **机械臂舵机**：位置舵机，角度就是距离。
- **载物台**：连续旋转舵机**没有位置反馈**，没法给"走多少"；只能折成"转多久"，
  所以 `PLT <ms>` 是定时点动（速度固定 40%），到点自动回停止脉宽。真要做距离，得换成位置舵机或加编码器。
- **速度只作为第二个可选参数**（`[hz]`），省略就用默认值；不传时间，也不依赖 `F` 的满速。

### 2.2 升降回位：`LIFT HOME` / `LIFT ZERO` / `LIFT ?`（2026-11-11）

升降没有限位开关，也没有编码器，所以固件自己维护一个**累计位置**（脉冲，正 = 下降，起点 0）。
**手动 `LIFT`、`CYC`、`TRG` 全部从 `Pick_LiftPulses()` 过**，都会累加，所以这个数就是
"现在离起点差多少脉冲"。

| 命令 | 作用 | 什么时候用 |
|---|---|---|
| `LIFT ?` | 打印 `pos=<n> pulses` | 想知道现在偏了多少 |
| `LIFT ZERO` | 把当前位置定义成 0 | 手动把升降开到最高处之后，重新对齐 |
| `LIFT HOME` | 按 `-pos` 走回起点，走完自动归零 | 跑完序列、或中途 STOP 之后对不回原位 |

⚠ 这是**指令值不是实测**：中途 `STOP`、单步超时、或丝杆打滑，都会让它和真实位置对不上。
真正对不上时，手动开到最高处再 `LIFT ZERO` 是最可靠的复位方式。
`LIFT HOME` 走完也会把累计值直接清 0（不再等 `LIFT done`），所以中途再 `STOP` 就又得重新对齐。

## 3. 任务循环 `CYC`

2026-11-11 改成**三段式**：**开场一次 → 每轮重复 → 收尾一次**。

| 段 | 步 | 动作 | 参数 |
|---|---|---|---|
| **开场**（只一次） | 1 | 先张开 | `PK_GRIP_APPROACH_DEG`，等 `PK_GRIP_OPEN_SETTLE_MS` |
| | 2 | 快降，留出末段 | `+(DOWN - APPROACH)` @ `PK_CYC_LIFT_HZ` |
| | 3 | 慢降贴近 | `+PK_GRIP_APPROACH_PULSES` @ `PK_GRIP_APPROACH_HZ` |
| **每轮**（×N） | 1 | 夹紧 | `PK_GRIP_CLOSE_DEG` = 180°，等 `PK_GRIP_CLOSE_SETTLE_MS`（800 ms） |
| | 2 | 慢抬离 | `-PK_GRIP_LIFTOFF_PULSES` @ `PK_GRIP_LIFTOFF_HZ` |
| | 3 | 快升到放料高度 | `-(UP - LIFTOFF)` |
| | 4 | 转到放料侧 | `-PK_CYC_ROT_DEG` = -132° @ 2000 Hz |
| | 5 | 松开 | `PK_GRIP_OPEN_DEG` = 30°，等 400 ms |
| | 6 | 载物盘走一格 | `PK_CYC_PLAT_MS` = 413 ms @ 40% |
| | 7 | 转回取料侧 | +132° |
| | 8 | 快降，留出末段 | `+(UP - APPROACH)` |
| | 9 | 慢降回取料位 | `+PK_GRIP_APPROACH_PULSES` |
| **收尾**（只一次） | 1 | 取料位 → 最高处 | `-PK_CYC_LIFT_DOWN_PULSES` = -8000 |

**"下降 8000"整条序列只出现一次**（开场），之后每轮都在取料位和放料高度之间做 6000 的往复。
每轮结束时高度、朝向都和开始时完全一样，所以 `CYC 3` 就是三段完全相同的工作循环，
跑完升降自动回到最高处（`lift_pos_pulses` 也归零），可以直接发 `CYC`、`TRG` 或开去下一个工位。

> 旧版是"一张表每轮整表重跑"，导致每轮都要 +8000/-8000 上下跑满行程、且忘记回位时高度会一轮轮漂。
> 现在拆成 `cycle_prologue[] / cycle_body[] / cycle_epilogue[]` 三张表，
> 状态机由 `cycle_phase` 推进。改动作仍然只改表。

`CYC <n>` 连跑 n 轮（默认 `PK_CYC_ROUNDS_DEFAULT` = 3、上限 `PK_CYC_MAX_ROUNDS` = 20），
**只在开始和结束时各回一行**（`CYC start` / `CYC done`），中间每一步的逐条回显全部静音——
一整场 6 站 × 3 轮就是一百多行，会把 TASK 的走位行刷没。错误和超时仍然照常打印；
`STOP` / `E 0` 随时中止。

**起点**：升降停在丝杆最高处。开场把升降降到取料位、收尾再升回最高处，
所以**整条序列结束时的高度和开始时一致**；`TRG` 同样以最高处开始和结束，
`CYC` 和 `TRG` 可以任意接续，不需要手动回位。

**改升降快慢**：只改 `PK_CYC_LIFT_HZ`（默认跟 `PK_LIFT_HZ` 走），行程由
`PK_CYC_LIFT_DOWN_PULSES` / `PK_CYC_LIFT_UP_PULSES` 决定，两者互不影响。
`hz` 上限 20000（`#error` 拦），单步超时是 `PK_CYC_STEP_TIMEOUT_MS` = 10 s——速度降得太低
（8000 脉冲 / 10 s 以下，即 800 Hz 以下）会先撞超时，要同时放大这个值。

### 3.2 卸料序列 `TRG`（2026-11-11）

从**载物台（旋转舵机那一侧）**取一件，转到放料侧，下降到地面放开，再转回来、升回最高处。
2026-11-16 起下降前先张开，末段放慢，松开后先抬离再转，避免扫到刚放下的料：

| 步 | 动作 | 参数 |
|---|---|---|
| 1 | 先张开 | `PK_GRIP_APPROACH_DEG`，等 400 ms |
| 2 | 快降到取料位附近 | `PK_TRG_PICK_PULSES - APPROACH` @ `PK_TRG_LIFT_HZ` |
| 3 | 慢降贴近 | `PK_GRIP_APPROACH_PULSES` @ 2000 Hz |
| 4 | 夹紧 | `PK_GRIP_CLOSE_DEG` = 180°，等 800 ms |
| 5 | 慢抬离 | `-PK_GRIP_LIFTOFF_PULSES` |
| 6 | 快升回最高处 | `-(PICK - LIFTOFF)` |
| 7 | 转到放料侧 | `PK_TRG_ROT_DEG` = +132° @ `PK_CYC_ROT_HZ` |
| 8 | 快降，留出末段 | `DROP - APPROACH` |
| 9 | 慢降放到地面 | `PK_GRIP_APPROACH_PULSES` @ 2000 Hz |
| 10 | 松开 | `PK_GRIP_OPEN_DEG` = 30°，等 400 ms |
| 11 | 先抬离再转 | `-PK_GRIP_LIFTOFF_PULSES` |
| 12 | 转回取料侧 | `-132°` |
| 13 | **升回最高处** | `-(DROP - LIFTOFF)` |

地面那一段的脉冲总数仍是 `PK_TRG_DROP_PULSES` = **41000**（2026-11-17 实测），只是最后 1200 个脉冲放慢。

⚠ **三条硬约束**：

1. **起点必须是丝杆最高处**。升降没有限位开关，从别的高度发 `TRG` 会多走整段行程顶死。
2. **`41000` 是 2026-11-17 实测值**（顶部 → 地面放料位）。旧值 37000 偏小 4000，会在离地还有一段就松爪；
   早先量到的 14000 是更早一版机构的数，已作废。
   第一次仍建议分步 `LIFT 20000` → `LIFT 30000` → `LIFT 41000` 确认行程，再发 `TRG 1`。
3. 单步超时沿用 `PK_CYC_STEP_TIMEOUT_MS` = 10 s：30000 Hz 下 41000 脉冲约 1.37 s（含斜坡 ~1.45 s）；
   若把 `PK_TRG_LIFT_HZ` 降到 3700 Hz 以下就会先撞超时。

`TRG <n>` 连跑 n 轮（默认 `PK_TRG_ROUNDS_DEFAULT` = 1、上限 `PK_TRG_MAX_ROUNDS` = 20），
和 CYC 一样**只在开始/结束各回一行**（单步回显静音），跑完回 `TRG done (n rounds)`。
TRG 没有"最后一轮跳过"的步，每轮动作完全相同。

| 参数 | 默认 | 什么时候要改 |
|---|---|---|
| `PK_ARM_DEG_MIN/MAX`、`PK_ARM_US_MIN/MAX` | 0..180° / 1000..2000 µs | 舵机实际行程和脉宽不一致时 |

| `PK_CYC_LIFT_HZ` | 30000（= `PK_LIFT_HZ`） | **`CYC` 的升降速度，改这一个数就改整轮快慢** |

| `PK_TRG_PICK_PULSES` | 4000 | `TRG` 第 1 步：最高处 → 载物台取料位 |
| `PK_TRG_DROP_PULSES` | 41000 | `TRG` 第 8 步下降 / 第 13 步上升（**2026-11-17 实测：顶部→地面**） |
| `PK_TRG_LIFT_HZ` | 30000（= `PK_CYC_LIFT_HZ`） | `TRG` 的升降速度 |
| `PK_TRG_ROT_DEG` | 132 | `TRG` 的旋转角（第 4 步 +132、第 7 步 -132） |
| `PK_TRG_ROUNDS_DEFAULT` / `PK_TRG_MAX_ROUNDS` | 1 / 20 | `TRG` 默认轮数与上限 |
| `PK_DROP_RELEASE_PULSES` | 41000 | `DROP` 的释放/对准高度（顶部→地面）；留 1~2 mm 余量就减 400~800 |
| `PK_DROP_ALIGN_COARSE_MM` | 15 | `DROP` 顶部粗对准容差（宽视野） |
| `PK_DROP_ALIGN_TOL_MM` | 2 | `DROP` 底部精对准容差；1 环要 ≤1.5 mm，稳了再压到 1 |
| `PK_DROP_ALIGN_TIMEOUT_MS` | 25000 | `DROP` 对准阶段超时 |

所有非法组合有 `#error` 拦。

## 5. 首次上板顺序（**必须按这个来**）

1. **不接机构**，`E 1` 后 `ROT 10`，示波器量 PD12 应是 2000 Hz、约 89 个脉冲、持续约 44 ms
   （10° × 3200 / 360 ≈ 89 脉冲，2000 Hz 下 44 ms）。
2. 接旋转台，`ROT 90` / `ROT -90` 各一次，记下物理方向。
3. **升降先给最小行程**：先 `LIFT 200` 看方向对不对，再用 `LIFT 2000` / `LIFT -2000`
   各走一次量实际位移，算出每脉冲多少 mm。
4. 舵机：先 `ARM 90`，量 PB14 是 50 Hz、1500 µs；再把 `ARM 0` / `ARM 180` 看机械是否顶死。
5. 载物台：`PLT 500` 应转半秒后自停，`PLT -500` 反向；转反了改 `PK_PLAT_SIGN`。
6. 都对了先 `CYC 1` 跑一轮，**手放在急停/断电开关上**；确认起点高度和方向后再跑 3 轮。

## 6. 已知限制

- **升降没有限位、没有原点**：`LIFT` 是按脉冲数点动，**给多了就直接顶死**（没有软件停机兜底），
  所以第一次一定从小脉冲试起。要真正可用得先给 PD6/PD7 接限位（板上是空的）。
- **升降断电会下滑**：`E 0` 或复位后 PC9 拉高，垂直丝杆平台会因自重下落。
  `STOP` 只停脉冲、保持使能，比 `E 0` 安全。
- **断电后位置未知**：平台已经下滑，但固件 `lift_pos_pulses` 上电清零、仍以为在最高处。
  此时**不要**直接 `LIFT 41000` / `CYC` / `TRG` / `DROP`（会从低位再往下走顶死）。
  先小步向上回顶（`LIFT -2000`…），到顶后 `LIFT ZERO`，`LIFT ?` 确认 0 再动作。
  `IN` 可看 `top/bottom/home` 输入；PD6/PD7 目前没接限位，读到的一直是 0。
- **旋转台没有编码器**：`ROT` 的角度是开环估算，`PK_ROT_PULSES_PER_REV` 错多少，角度就错多少。
- **载物台只能按时间**：`PLT <ms>` 的速度固定 40%，没有角度反馈；角度得自己标 `deg/ms`
  （用 1～2 s 长跑量总转角，短脉冲受起停滞后影响大），同一 ms 的重复性约 ±10～20%。
- **`CYC` 不判到位**：没有夹爪检测、没有料检测，跑到第 7 步就算一轮成功。
- `CYC` 与底盘 `TASK` 互不干扰（可以边跑路线边取放），两者都只能靠 `STOP` 停；
  同时跑之前先想清楚，`CYC` 期间别让车撞到工位。
- `ARM` / `PLT` 不要求 `E 1`（它们不经过 `Step6` 的使能门），但要求 `Servo_Init()` 已经跑过——
  生产入口 `Board_InitStep6()` 会做。

## 7. 脉冲 ↔ 距离 ↔ 时间

**距离**由第一个参数决定，**时间** = 脉冲数 ÷ 频率。两者分开，改速度不会改行程。

`LIFT` 给的是脉冲数，换算成 mm：

```
mm = 脉冲数 × 丝杆导程_mm ÷ PK_LIFT_PULSES_PER_REV
```

例：导程 8 mm、`PK_LIFT_PULSES_PER_REV` = 3200 → 400 脉冲 = 1 mm。
标定方法：`LIFT 32000`（低速 `LIFT 32000 2000`）走一次，量实际走了多少 mm，
反算 `PK_LIFT_PULSES_PER_REV` 和导程。

`CYC` 的 7900 脉冲要多久，只取决于 `PK_CYC_LIFT_HZ`（常用速度见下表）：

| `PK_CYC_LIFT_HZ` | 7900 脉冲要多久 | 转速（3200 脉冲/转） |
|---|---|---|
| 4000 | 2.0 s | 75 rpm |
| 8000 | 1.0 s（实测含斜坡约 1.06 s） | 150 rpm |
| 10000（2026-11-11 前） | 实测 850 ms | 188 rpm |
| 12000（2026-11-17 前） | 理论 660 ms，含斜坡约 710 ms | 225 rpm |
| 18000（2026-11-17 一档） | 理论 440 ms，含斜坡约 500 ms | 338 rpm |
| **30000（现默认）** | **理论 263 ms，含斜坡约 330 ms** | 562 rpm |
| 40000（Step6 硬上限） | 0.2 s | 750 rpm |

想更快：

1. **`CYC` 里的升降**：改 `PK_CYC_LIFT_HZ`（现跟 `PK_LIFT_HZ` = 30000）。提速必须配**三段斜坡**
   （`PK_AXIS_RAMP_MS` = 120 ms、`PK_AXIS_RAMP_PERMILLE` = 400‰）：起转 40% → 恒速 → 收转 40%。
   STEP/DIR 模式不加斜坡，一万 Hz 的阶跃会跟丢或报过载。固件硬上限 40000 Hz。
2. **手动 `LIFT`**：加第二参数，`LIFT 8000 30000` = 8000 脉冲、30000 Hz 走；
   不带参数用 `PK_LIFT_HZ`。速度只影响走这段的时长，不影响走多远。
3. **改机械或细分**：细分从 16 降到 8，同样脉冲数下走的距离翻倍、分辨率下降；
   换大导程丝杆同理。改完 `PK_LIFT_PULSES_PER_REV` / `PK_CYC_LIFT_DOWN_PULSES` /
   `PK_CYC_LIFT_UP_PULSES` / `PK_TRG_PICK_PULSES` / `PK_TRG_DROP_PULSES` 要全部重标。

**反过来的风险**：升降没有限位，脉冲给多了照样顶死。速度提高只是让顶死来得更快。

### 3.3 单次抓取 `GRAB` / 放置 `PLACE`（2026-11-16）

给视觉对准用，不进 `TASK` 路线。命令是 `GRAB <cls> [tol_mm] [HOLD]`（cls 和 `ALIGN` 同一套）。

1. 底盘按 `$V` 把目标对到夹爪正下方，目标停稳且连续 3 帧进容差才算锁定。
2. 锁定后才下降取料：张开 → 快降 → 慢降贴近 → 夹紧（800 ms）→ 慢抬离。
3. **默认接着放料**（和 `CYC` 每轮后半段完全一致）：升到放料高度 → 转
   `-PK_CYC_ROT_DEG`（132°）→ 松开（400 ms）→ 载物台走一格 `PK_CYC_PLAT_MS` →
   转回 `+PK_CYC_ROT_DEG` → 升回最高处。
4. 加 `HOLD` 就停在"夹着料、最高处"（`GRAB 3 8 HOLD` 或 `GRAB 3 HOLD`），
   之后可以 `PLACE` 单独跑一次放料；调试夹爪时用这个。
5. 对准失败、超时、中途 `STOP`，都不下降；`GRAB ... HOLD` 之后 `PLACE` 之前也不用重新对准。

脉冲净值：`+(DOWN-APP)+APP -LIFTOFF -(UP-LIFTOFF) -(DOWN-UP) = 0`，
结束时累计位置回到 0，可以直接接 `CYC` / `TRG` / 下一轮 `GRAB`。
`PLACE` 的表是 `+(DOWN-UP) → 转 → 松 → 盘 → 转回 → -(DOWN-UP)`，同样净 0。

起点必须是丝杆最高处，而且固件记的累计位置要是 0（`S` 里的 `LIFT pos`）。
不是 0 就直接 `ERR GRAB lift not home` / `ERR PLACE lift not home`，
先 `LIFT HOME` 或手动开到最高处再 `LIFT ZERO`。

取料行程用 `PK_CYC_LIFT_DOWN_PULSES`（现 8000），放料高度用 `PK_CYC_LIFT_UP_PULSES`
（现 6000，即比最高处低 2000）；转角和载物台走格直接用 `PK_CYC_ROT_DEG` / `PK_CYC_PLAT_MS`。
夹爪还没在这个高度上夹过料的话，先用 `LIFT` 单步确认 8000 够得着，再发 `GRAB`。

### 3.4 圆环放置 `DROP`（2026-11-17）

**顺序（15 步，连续脉冲已合并）**：

1. 张开 30°（`PK_GRIP_OPEN_DEG`）
2. 转 +132° 到放料侧（仍在最高处）
3. 顶部粗对 stage=0（`PK_DROP_ALIGN_COARSE_MM` = 15 mm）
4. 降 41000（`PK_DROP_RELEASE_PULSES`）
5. 底部精对 stage=1（`PK_DROP_ALIGN_TOL_MM` = 2 mm，读数字核对 n）
6. 升 37000 到取料位 4000（`PK_DROP_RELEASE_PULSES - PK_TRG_PICK_PULSES`）
7. 转 -132° 回取料侧
8. 再降 2000 到 6000（`PK_CYC_PLACE_DOWN_PULSES`）
9. 夹紧 180°（`PK_GRIP_CLOSE_DEG`）
10. 升 4000 到 2000（`PK_TRG_PICK_PULSES`）
11. 转 +132° 到放料侧
12. 降 38000 到 40000（`PK_DROP_RELEASE_PULSES - 1000 - PK_CYC_PLACE_DOWN_PULSES`）
13. 张开 30° 放料
14. 升 40000 回最高处（`PK_DROP_RELEASE_PULSES - 1000`）
15. 转 -132° 回取料侧

角度：张开 **30°**、夹紧 **180°**。第 6 步之后底盘不再动，10/12/15 的 ROT 回程精度决定落点。

为什么先空爪对准：夹着料时料挡在相机正中，1 环（Φ+3）单边只有 1.5 mm 余量，内圈基本看不见；
空爪能看全 6 个同心圆。

失败/中断处理：对准超时（25 s）或失败 → 停轴 + 自动把升降升回最高处；`STOP` / 手动命令抢占 →
`Pick_DropAbort()`，先停轴、再由 `Pick_Poll` 延迟升回，不会停在半空。

起点：丝杆最高处、载物台上有料、`E 1`。回显：
`DROP start: align empty, then pick+place (STOP aborts)` … `DROP done, ring placed`。

### 3.5 动作结束自动回最高（2026-11-17）

`CYC` / `TRG` / `GRAB` / `PLACE` / `DROP` 正常跑完、或中途 `STOP` / 超时 / 对准失败，
只要 `lift_pos_pulses != 0`，`Pick_Poll` 里会自动发一次 `LIFT HOME`（`PK_LIFT_HZ` 速度）把升降升回最高处；
已经在 0 时不动作。`LIFT ZERO` 会取消这个待回位（避免你在手动对零时它突然动）。
回位那一行会打 `OK LIFT home, N pulses`。
