# 整合工程使用说明

`MDK-ARM/Vehicle_Integrated.uvprojx` 是**唯一可构建工程**，编译定义 `VEHICLE_INTEGRATED_APP`。2026-11-09 起，`HMI` / `WHEEL` / `RIG` / `CHASSIS_STEP` 不再单独做 Target，工程文件在 `MDK-ARM/_legacy/Bench_Tests.uvprojx`。

当前固件按**新底板（六轴步进）**启动：`Core/Src/main.c` 调用 `Board_InitStep6()`，再进 `App/Src/vehicle_app.c`。不能走 `Board_Init()`，否则 TIM2/TIM3/TIM4 会被配成编码器，抢走 C / D / 旋转的 STEP。

命令、标度、路线与拆分前的 `CHASSIS_STEP` 台架一致。实现按层分开，不堆在一个文件里：

| 层 | 文件 | 回答什么 |
|---|---|---|
| 驱动 | `BSP/Src/board_step6.c` | 这一轴怎么出脉冲、怎么改方向、怎么使能 |
| 实现 | `App/Src/chassis_motion.c` | 点动、平移、自旋、三段加减速 |
| 实现 | `App/Src/chassis_task.c` | 比赛路线表，只排步骤 |
| 实现 | `App/Src/vehicle_app.c` | 串口命令和上电节拍 |
| 参数 | `App/Inc/chassis_config.h` | 轮径、L、三档速度、斜坡、航点 |

旧老板的 `A ON` / `G CLOSE` 不在这份固件里。那套命令依赖直流电机和 `Board_Init()`，和新板的 STEP 定时器冲突；源文件仍留在 `Tests/`，没有再挂进生产工程。

## 构建与下载

1. 关掉已打开的 µVision 后再改工程文件。用 Keil 打开 `MDK-ARM/Vehicle_Integrated.uvprojx`。
2. 选择 `Vehicle_Integrated` Target，执行 Rebuild。
3. 通过 SWD 下载 `MDK-ARM/Vehicle_Integrated/Vehicle_Integrated.hex`。
4. 首次下载断开电机动力电源，只留逻辑电源，先确认欢迎语和 `H`。

PowerShell 构建命令：

```powershell
& 'D:\Using Tool\Keilvvv5\Keil_v5\UV4\UV4.exe' -r 'MDK-ARM\Vehicle_Integrated.uvprojx' -j0 -o 'MDK-ARM\Vehicle_Integrated\build.log'
```

## 串口命令

USART1（PA9/PA10，有线）和 UART5（PC12/PD2，蓝牙）都是 115200 8N1。回复走命令来的那个口。有线口只认 CR/LF；蓝牙口静默 50 ms 也算一行结束。一行最多 39 字节。

上电不发脉冲、底盘失能。未使能时 `M` / `MALL` / `J` / `L` / `R` / `A` / `TASK` / `ROT` / `LIFT` / `CYC` / `TRG` 回 `ERR not enabled`。

| 命令 | 行为 |
|---|---|
| `?` / `S` | 使能、满速、点动、任务步骤、A～D 四轮频率和方向、ROT/LIFT 频率、舵机脉宽、CYC 进度 |
| `H` / `HELP` | 命令表 |
| `P` | 六轴引脚表 |
| `E 0` / `E 1` | 三根 nEN（底盘 PD3 + 旋转 PC8 + 升降 PC9）。`E 0` 会取消点动、`TASK`，并中止 `CYC` |
| `F [hz]` | 满速频率，默认 8000；不带参数只回显 |
| `M <a-d> <permille>` | 单轮速度，±1000 |
| `MALL <permille>` | 四轮同速 |
| `L` / `R <mm> [mm/s]` | 麦轮左移 / 右移**按距离**点动（1..5000 mm，默认 400 mm/s），走够自停；有陀螺时自动保持航向，回显带 `(hdg err=…)` |
| `A <deg>` | 原地转，正逆时针，开环计步 |
| `D <a-d> <0\|1>` | 单轮方向 |
| `J <a-d> <steps> [hz]` | 点动 N 步 |
| `TASK` | 跑 v0.6 航点路线；**有 HWT101 时转身按 yaw 闭环、直行做航向保持**。横移 `>= CS_TASK_EDGE_MIN_MM`（默认 1200 mm）的整边会自动改成"转 90° → 直行 → 转回"，半个边仍直接横移。**若这一步后面紧跟的就是 `TURN_ABS`，"转回"会被跳过**，由下一步按绝对航向一次转过去（2026-11-11 修，省掉两次多余的 180°）。到站的 `TASK_CYC` 步会自动启动 `CYC` 并等它跑满 `CS_MAP_WORK_CYC_ROUNDS` 轮，**机构没跑完不会开走** |
| `ROT <deg> [hz]` | **旋转台**按角度点动，±360，开环计步；`hz` 省略用默认 2000 |
| `LIFT <pulses> [hz]` | **升降台**按脉冲点动（±200000），走够就停；`hz` 省略用默认 30000 |
| `LIFT HOME` / `LIFT ZERO` / `LIFT ?` | 升降**回起点**（按累计位置反向走回）/ 把当前位置设为原点 / 查累计位置 |
| `ARM <deg>` / `ARM OFF` | **夹爪/机械臂舵机**（PB14）0..180° |
| `PLT <ms>` / `PLT OFF` | **载物台舵机**（PB15）按时间点动：转 `ms` 毫秒后自停，速度固定 40%（`PK_PLAT_JOG_PERMILLE`）；负毫秒 = 反向 |
| `CYC [n]` | 连跑 n 轮正式任务（默认 3）：降 → 夹 → 升 → 转 → 松 → 盘走一格 → 转回 |
| `TRG [n]` | 卸料 n 轮（默认 1）：载物台夹起 → 降到地面 → 松开 → 升回最高处。**起点必须是丝杆最高处** |
| `Y` | 陀螺状态：yaw、角速度、帧龄、好帧/坏帧数 |
| `Z` | 陀螺 yaw 清零（`TASK` 启动和 `RESET` 也会自动清） |
| `X 0` / `X 1` | 关/开平移段航向保持（现场 A/B 对比） |
| `STOP` | 全停：底盘、旋转/升降、载物台，`TASK` 和 `CYC` 一起取消 |

底盘参数和非法值检查在 `App/Inc/chassis_config.h`；机构（升降/旋转/舵机/CYC）参数在
`App/Inc/pick_config.h`。接线、速度档和上板顺序见 [底盘步进台架](底盘步进台架.md)，
机构命令与 `CYC` 时序见 [机构指令：升降/旋转/舵机](机构指令_升降旋转舵机.md)。

## 上电安全初态

`Board_InitStep6()` 只做 GPIO、六个 STEP 定时器和五路串口，不启动 PWM。`VehicleApp_Begin()` 再次失能并停脉冲。复位后不会自动走。PC0 心跳灯 500 ms 翻转，只表示主循环还在跑。
