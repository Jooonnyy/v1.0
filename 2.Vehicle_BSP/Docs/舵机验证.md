## Target 与动作

使用 `MDK-ARM/Bench_Tests.uvprojx` 的 `Servo` Target，编译定义为 `SERVO_TEST`，入口为 `Tests/Src/servo_smoke.c`。

测试只执行一轮：

```text
125° 夹紧指令 → 保持 5 秒 → 每 400 ms 减少约 2° → 70° 松开指令 → 保持
```

参数位于测试文件顶部：`GRIP_CLOSED_DEG`、`GRIP_OPEN_DEG`、`MOVE_STEP_DEG`、`MOVE_INTERVAL_MS`、`GRIP_HOLD_MS` 和脉宽端点。默认按 0°=1000 µs、180°=2000 µs 线性换算，因此 125° 约为 1694 µs，70° 约为 1389 µs。这里的角度是控制刻度，不是夹爪实际角度测量值。

生产固件上电保持 PWM 关闭；`G CLOSE`、`G OPEN` 分别直接设置 125° 和 70°，`G OFF` 或 `STOP` 关闭 PWM，不执行渐变测试。

## 供电与安全

1. 打开 SW3 后先测 `5V_SERVO` 对地电压，确认舵机地与 MCU 共地。
2. 舵机启动和堵转电流可能超过 1 A，不得从 MCU 3.3 V 取电。
3. 若动作导致 MCU 复位或屏幕异常，检查 5 V 支路容量，并在舵机插座附近增加合适的储能与去耦电容。
4. 首次测试卸下舵盘或保证连杆有充分空间。靠近机械止挡、持续嗡鸣或发热时立即断电。
5. `Servo_SetPulseUs()` 接受 500～2500 µs 只代表软件范围，不代表机构全行程安全。

## 操作

1. 选择 `Servo` Target 并 Rebuild。
2. 下载 `MDK-ARM/Bench_Tests/Servo/Servo.hex`。
3. 接通 `5V_SERVO` 后观察完整动作、方向、电源电压和机构止挡。
4. USART1 PA9 TX、115200 8N1 会输出当前指令角度和脉宽，可用于记录标定结果。
