## 1. 接线

| 执行器 | 信号 | MCU 脚 | 备注 |
|---|---|---|---|
| 升降台（张大头 ZDT） | STEP / DIR / EN / ALM | **PD0 / PD1 / PC8 / PD14** | EN 低有效（`LE 1` 拉低使能）；**ALM 未接线**，固件默认忽略（见下） |
| 旋转台（张大头 ZDT） | STEP / DIR / EN / ALM | **PD4 / PD5 / PC9 / PD15** | 同上 |
| 机械臂舵机 | PWM | ~~PA7（TIM14_CH1）/ PE5（TIM9_CH1）~~ → **PB14 / TIM12_CH1**（V2） | 50 Hz，500..2500 us，上电不出脉冲。老板的两套接法与 `U5_SERVO_USE_PA7` 开关 **2026-11-09 已删除**；见 `Docs/PINMAP.md` §1.3 |
| 载物台舵机 | PWM | ~~PE6（TIM9_CH2）~~ → **PB15 / TIM12_CH2**（V2） | 同上；PE6 在 V2 上是 B 轴 STEP |
| 运行指示灯 | — | **PC0**（核心板板载 LED，**低电平点亮**） | 2026-10-13 新增：500 ms 心跳，只表示"固件在跑"；**与电源指示灯无关** |
| 底盘电机 A | PWM / IN1 / IN2 / STBY | **PE9 / PE7 / PE8 / PD2** | TB6612 **U2** 通道 A |
| 底盘电机 B | PWM / IN1 / IN2 | **PE11 / PE10 / PE12** | 与 A 共用 U2 的 STBY **PD2** |
| 底盘电机 C | PWM / IN1 / IN2 / STBY | **PE13 / PB11 / PB12 / PD3** | TB6612 **U3** 通道 A |
| 底盘电机 D | PWM / IN1 / IN2 | **PE14 / PB13 / PB14** | 与 C 共用 U3 的 STBY **PD3** |
| 蓝牙 | TXD→PA3 / RXD→PA2 | USART2 | 115200 8N1；配置见 `Docs/HC05无线串口.md` |

- 逻辑信号必须**共地**；PA2/PA3 是 **3.3V** 逻辑，不能接 5V。
- 两个 ZDT 驱动器都要设成 **STEP/DIR（脉冲+方向）**模式；PLC 输入接法/输入电压以实物手册为准。
- **舵机要独立 5~6V 供电**（不要用板载 3.3V），并与逻辑共地；两路舵机同时动时注意电流。
- 若要互换两个轴的角色，只改 `rig_smoke.c` 里的 `axis_stepper[]` / `axis_label[]` 两张表。
- 底盘电机是 12V 动力电，**TB6612 的 VM 与逻辑 3.3V 分开供**；用 `M` / `MR` 转电机前**把四个轮子架空**。

## 2. 上电初态（安全）

- **不发脉冲、两轴 `en=0`（失能）、两个舵机不出 PWM、四路电机输出 0 且两片 TB6612 处于待机**，
  一切等命令；
- **`Motors_All` 的"上电 3 秒后自动跑序列"没有搬进来** —— 本 Target 上电绝不会自己动电机；
- `STOP` 停步进脉冲 + **四路电机全停回待机**（并中止 `MR` 序列）；正在做 `PT`/`PA` 角度运动时才会
  顺手把载物台回中位 —— **它停不掉 `P <permille>` 的连续转**（那种情况要 `P 0` 或 `PO`）；
  `STOP` **保留**步进使能（保持力矩）；`LE 0` / `RE 0` 才释放电机 —— **带载释放前先支撑平台**；
- 步进**没有软限位、没有回零**（板上没接限位信号）：首次只用小步数点动，先确认方向与行程；
- 蓝牙链路**没有断线检测**，断线不会自动停 → **不能用蓝牙代替硬件急停**；
- 运动期间回显会延迟到停稳后发（**排队 4 条**，超出才丢并提示 `WARN n deferred replies dropped`），
  这是为了不让阻塞串口把脉冲节奏拉长（`AGENTS.md` 第 6 节）；
- **运动期间 `LE/RE` 与 `LD/RD` 会被拒绝**（回 `ERR axis is moving; send STOP first`）：
  ZDT 在脉冲中途掉使能会丢步，带载释放会直接掉平台，中途换向也会丢步；先 `STOP` 再改。
- **复位后板载 PC0 LED 开始 500 ms 闪烁**（`RIG_LED_HEARTBEAT_MS`，参数区可调）：
  这是"固件还在主循环里跑"的指示 —— 卡在阻塞调用里（串口超时、脉冲预算吃满）它就不翻了，
  比串口回显更早暴露。⚠ 它**不是**核心板上那颗硬连 USB 5V 的**电源指示灯**：
  只给台架电源、USB 拔掉时电源灯灭属正常，与本灯无关。

### 3.5 四路底盘电机（`M` 命令，从 `Motors_All` 搬过来）

内容与 `Motors_All` Target（`Tests/Src/motors_all_smoke.c`）**同一套**：同一张 12 段序列、
同一个 **±250‰（25%）** 上限、同一条"`Motor_Set()` 不碰 STBY"的坑。区别只有三点：

1. **由命令触发**（`MR`），不再上电自动跑；
2. 和步进、舵机**共用一条蓝牙命令口**（所以运动期间的回显同样会延迟排队）；
3. 手动命令有 `MALL`（四路一起）和"只停一路"（`M c 0`），`H` 还能直接看到 STBY 电平。

| 通道 | TB6612 | PWM | IN1 | IN2 | STBY |
|---|---|---|---|---|---|
| A | U2 通道 A | PE9 | PE7 | PE8 | PD2 |
| B | U2 通道 B | PE11 | PE10 | PE12 | PD2 |
| C | U3 通道 A | PE13 | PB11 | PB12 | PD3 |
| D | U3 通道 B | PE14 | PB13 | PB14 | PD3 |

`MR` 的 12 段（全程 ≈ 14 s，每段都在串口打一行 `MOTOR [n/12] ...`）：

| 段 | 动作 | 时长 |
|---:|---|---:|
| 1 / 3 / 5 / 7 | A / B / C / D 依次单独正转 | 各 1500 ms |
| 2 / 4 / 6 / 8 / 10 / 12 | `all stop` | 各 800 ms |
| 9 | 四路同时正转 | 1500 ms |
| 11 | 四路同时反转 | 1500 ms |

- 参数在 `rig_smoke.c` 参数区：`RIG_MOTOR_MAX_PERMILLE` / `RIG_MOTOR_SEQ_RUN_MS` /
  `RIG_MOTOR_SEQ_GAP_MS` / `RIG_MOTOR_SEQ_TIMEOUT_MS`，都有 `#error` 校验；
- **唯一的兜底**是 `RIG_MOTOR_SEQ_TIMEOUT_MS`（40 s）硬超时：到时无条件四路全停；
  手动 `M` / `MALL` 的输出**没有**自动停机，靠 `MS` / `STOP` / 断动力电；
- 序列跑完 / 被中止 / 硬超时都会 `Motor_StopAll()`，两片 TB6612 回待机（电机不再有力矩）；
- `M c 0` 只把 C 路写 0，**不会**把两片压回待机；要彻底断输出用 `MS` / `STOP`；
- ⚠ **转电机前把四个轮子架空**；12V 电机在 15% 以下可能低于启动死区而不转。

### 夹爪流程（`GRIP`，值沿用老工程 `servo_smoke.c` 的实测工作点）

| 参数（`rig_smoke.c` 参数区） | 现值 | 说明 |
|---|---|---|
| `RIG_GRIP_OPEN_US` | 1389 | 老工程 70°，松开点 |
| `RIG_GRIP_CLOSE_US` | 1694 | 老工程 125°，夹紧点 |
| `RIG_GRIP_OVERSHOOT_US` | **30** | **超压**：夹紧时比接触点再压 30 µs，吃满夹持力（改 0 可做对照） |
| `RIG_GRIP_HOLD_MS` | 5000 | 夹紧保持时间 = 最长堵转时间 |
| `RIG_GRIP_STEP_US` / `_MS` | 12 / 400 | 松开每 400 ms 退 12 µs（≈ 老工程的 2°/步） |

流程：`GRIP` → 夹到 **1724 µs**（=1694+30）→ 保持 5 s → 每 400 ms 退 12 µs →
到 **1389 µs** 结束。`S` 里的 `grip=` 是状态（0 空闲 / 1 保持 / 2 松开中）。

对照实验：把 `RIG_GRIP_OVERSHOOT_US` 改成 `0` 重编重烧，对比"手能不能掰开夹爪"，即可判断超压有没有用。
手动 `A` / `AU` / `AO` 会中止流程（手动优先）；`STOP` 会中止流程但**保持当前脉宽**（不会掉料）。

### 载物台"按角度转"是怎么实现的（时间推算，开环）

连续旋转型舵机**没有位置反馈**，所以"转到 N 度" = 用固定速度跑 `N ÷ 角速度` 秒，然后回中位停：

| 参数（`rig_smoke.c` 参数区） | 现值 | 怎么定 |
|---|---|---|
| `RIG_PLT_DEG_PER_S` | 90 | **必须实测**：`Z` → `P 1000` 计时 5 s → `P 0`，量转过的角度 θ，填 `θ/5` |
| `RIG_PLT_SPEED_PERMILLE` | 1000 | 转角度时固定用的速度（满速重复性最好） |
| `RIG_PLT_DIR_SIGN` | 1 | 转反了改 `-1`，不用动接线 |
| `RIG_PLT_ONEWAY` | 1 | `1` = 总是单向转到位（消回差）；`0` = 走最短路径 |

标定与验证：

```text
Z             角度清零
P 1000        满速正转，秒表计 5 秒
P 0           停
（量转盘转过的角度 θ，把 RIG_PLT_DEG_PER_S 改成 θ/5，重编重烧）
Z
PT 90         验证：应正好转 90°；差多少按比例微调 RIG_PLT_DEG_PER_S
```

**误差来源（必须知道）**：这是开环时间法 ——
① 舵机转速随电池电压变化（12 V 掉到 10 V 大约慢 15%，角度也差同样比例）；
② 转盘上有负载时转速也会变；
③ 所以：标定要在满电、用满速；只用单向转到位消回差；**要真正精确必须闭环**（编码器/限位/陀螺仪）。

**补记（2026-10-13，讲的是开环法本身的坑，与命令版本无关）**：

- **标速度必须用长跑**（像 `P 1000` 保持 5 s 那样）。舵机有几十 ms 启动滞后，用一两百 ms 的短跑
  反推速度会把滞后一起算进去、估出的值偏小；照它改 `RIG_PLT_DEG_PER_S` 会让所有命令都跑太短。
- **`DEG_PER_S` / `MIN_RUN_MS` / `MAX_RUN_MS` 是一组**：换算成角度 = 时间 × `DEG_PER_S` / 1000。
  改速度不同时看后两个，小角度会被 MIN 抬起来、时间上限也会突然允许转几十圈。
- **跑得比启动滞后还短时，现象是"完全不动"**，那不是 PWM 没输出，是时间不够。
  排查用 `H` 看 TIM9 的 `CCR2`（运动时应是 1000 或 2000，停下 1500），或者 `PU 1000` —— 它直接把
  脉宽给下去并一直保持，是判断"舵机到底有没有收到信号"最快的一条。

### 关于 ALM（报警输入）

- ALM 是 ZDT 驱动器的**故障指示输出**（过流/过温/保护动作时拉低），到 MCU 是**输入**；
- 固件把 PD14/PD15 配成 **输入 + 内部上拉**（`board_gpio.c` 的 `GPIO_PULLUP`）：
  **不接线时读高 = 无报警**，所以不接不会误停；
- 默认 `ALM 0`（忽略）。以后接上了就发 `ALM 1`，报警时该轴会自动停脉冲并打印
  `ALM LIFT(U1): pulses stopped ...`；`S` 的 `alm=` 是引脚原始电平，`almen=` 是当前是否采信。

- `A 90` → 0..180° 线性映射到 **1000..2000 µs**（整机机械可用范围；500/2500 是电气极限，打过去会顶死）；
- 映射不准就用 `AU <us>` 直接给脉宽标定，标定结果记在 `Docs/舵机验证.md`；
- 运动命令都是**非阻塞**的：一个轴在连续转的时候，另一个轴照样能点动，`S` / `STOP` 随时有响应。

## 4. 联调步骤（建议顺序，每步有判据）

1. **只给逻辑电、先不上动力电**：复位后应看到 `RIG ready: ...` + 状态行（`en=0`、`MOTOR A=0 B=0 ...`），
   舵机 `on=0`。判据：两轴不发热、不响、平台不动、轮子不动。
2. **舵机先动**（不涉及步进）：`A 90` → 机械臂到中位；`P 90` → 载物台慢速转（会一直转，`P 0` 停）；
   `AO` / `PO` 掉力矩。
   判据：动作平滑、没有堵转嗡嗡声；抖/不动先查舵机独立供电与共地，再 `PU 1000` 直接给脉宽试。
   接着试按角度：`Z` → `PT 90` → 应转约 90° 后自己停；判据是实际转角对不对
   （开环，误差按下面"载物台按角度转"那节标 `RIG_PLT_DEG_PER_S`）。
3. **升降台点动**：`LE 1` → `LV 2000` → `LD 1` → `LJ 20`。
   判据：平台朝一个方向走；反向 `LD 0` + `LJ 20`。用卡尺量 20 步的实际位移，反推 `mm/步`。
4. **升降台连续**：`LC 1` → 看几秒 → `STOP`。
   判据：`STOP` 后立刻停；`S` 里 `rem=0`、`pos` 不再增长。
5. **旋转台重复 3、4**：`RE 1` → `RV 2000` → `RD 1` → `RJ 20` → `RC 1` → `STOP`。
6. **两轴同时**：先 `LC 1`，再在另一个轴发 `RJ 20`。
   判据：两个轴都在动、互不阻塞（这是本次"分时脉冲预算"引擎要验的关键点）。
7. **四路电机（轮子先架空，再上 12V 动力电）**：`MM` 核对映射 → `M a 250` 只转 A → `M a 0` 停；
   B/C/D 各试一遍；`MALL 250` 四路一起 → `MS` 全停。
   判据：单路命令只有那一路转；`H` 里 `STBY PD2=1 PD3=1`（C/D 不转先看 PD3）；`MS` 后四路立即停。
8. **四路序列**：`MR` 跑完 14 s（或中途 `MS`）。
   判据：1/3/5/7 段分别只有 A/B/C/D 转；第 9 段四路同时转时电源不掉压、不复位。
9. **报警（可选，当前未接线）**：ALM 默认忽略。以后接上 PD14/PD15 后发 `ALM 1`，
   再故意触发驱动器报警，该轴应自动停脉冲并打印 `ALM ...`。
10. **遥控/遥测**：`T 1` 打开 5 Hz 六通道流（`pos1,pos2,rem1,rem2,arm_us,plt_us`）给 VOFA+ 或 `Tools/serial_scope.html`。
    ⚠ 同一口上文本和数字会交错，看波形时别同时敲命令；**遥测里没有电机占空比**，看电机得发 `M` / `S`。

## 5. 单位换算（细分和导程**尚未标定**，所以命令用"步"不用 mm）

```text
步数/转   = 200 × 驱动器细分          // 1.8° 步距角；细分 16 -> 3200 步/转
位移mm    = 步数 × 丝杆导程mm / 步数每转
角度deg   = 步数 × 360 / 步数每转 / 减速比
脉冲频率  = 1e6 / 周期us              // 2000us -> 500 脉冲/秒
转速rpm   = 60 × 1e6 / (周期us × 步数每转)
```

- 两个数（细分、导程/减速比）**必须实测**：走 1000 步量实际位移，反算；填进本文的表格再写进代码。
- 例：细分 16（3200 步/转）、导程 4 mm → 0.00125 mm/步；要走 20 mm 就是 16000 步。

## 6. 常见问题

| 现象 | 排查 |
|---|---|
| 蓝牙没回显 | 波特率 115200、接的是 PA2/PA3、模块是刚配对好的从机；发 `?` 看帮助 |
| `ERR axis disabled` | 先发 `LE 1`（升降）或 `RE 1`（旋转） |
| 有回显但电机不动 | 驱动器动力电、STEP/DIR 模式、EN 电平（低有效）、脉冲周期是否过大、细分是否设对 |
| 方向反了 | `LD 0` / `RD 0` 切换（软件方向，不用改线） |
| 舵机不动/抖动 | 舵机独立 5~6V 供电 + 共地；用 `AU 1500` 直接给脉宽试 |
| 载物台转起来停不下来 | `P <permille>` 给非零值就是"一直转"；发 `P 0` 或 `PO`。**`STOP` 停不掉它**（只有 `PT`/`PA` 进行中才回中位） |
| 载物台舵机完全不动 | 先 `PU 1000`（直接给脉宽并保持）：能转 = 固件通了，问题在命令或参数；不转 = 查供电/接线/信号 |
| 按角度转的圈数明显不对 | `RIG_PLT_DEG_PER_S` 没标定（见"载物台按角度转"那节）；标定要用 `P 1000` 保持 5 s 的长跑，别用短跑 |
| 第二路舵机没反应 | 确认载物台舵机接的是 PE6；不是就改 `pins/servo_u6.h` 后重编 |
| 一台动另一台不动 | 两个轴共用主循环分时发脉冲，`LV/RV` 周期别都设得太小（20 us 会让单轮预算被一个轴吃满） |
| 高速丢步 | 目前**没有加减速曲线**（恒速脉冲）；先把 `LV/RV` 放到 2000 us 以上 |
| `M` 有回显但轮子不转 | 先 `H` 看 `STBY PD2/PD3`：**0 = 待机，一定不转**（`MS` / `STOP` 会把它压回 0，之后单独 `Motor_Set` 不会唤醒）；再看 12V 动力电、TB6612 的 VM |
| 只有 C / D 不转 | **U3 的 STBY（PD3）没接通** —— 这是 U2 已验、U3 未验的已知差异（`Motors_All` 时代就记录过） |
| 某一路只有嗡嗡声 | 250‰ 低于该路启动死区或电流不够；临时把 `RIG_MOTOR_MAX_PERMILLE` 调到 400 重编（**属于未验证区间**） |
| 第 9 段（四路同时）板子复位 | 12V 电源带不动 4 个电机 |
| 发了 `M a 250` 却四路都在动 | 上一条命令是 `MALL`；`M c 0` 只清 C 路，其它路保持原值，要全停用 `MS` / `STOP` |
| `MR` 的回显缺了几行 | 有步进在连续转时回显在排队（4 格），超出会丢并提示 `WARN n deferred replies dropped` |
