# Vehicle BSP（STM32F407VET6）

本工程为车辆控制板的统一固件工程。代码按 `Core → BSP → App` 分层。**当前只保留一个可构建工程** `MDK-ARM/Vehicle_Integrated.uvprojx`（2026-11-09 起；新底板六轴步进）。`HMI` / `WHEEL` / `RIG` / `CHASSIS_STEP` 台架工程已移入 `MDK-ARM/_legacy/`，不再作为入口。上电后生产固件不发脉冲、底盘失能，只响应 USART1 或 UART5 的文本命令。
